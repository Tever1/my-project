# Project Context

Обновлено: 2026-09-20. Это компактная оперативная память проекта. История
чатов и старые отчёты не являются источником истины; при расхождении проверять
текущий код.

## Project goal

Party Games Hub — локальный/сетевой хаб вечериночных игр. Один экран создаёт
комнату и работает как общий TV, игроки подключаются с телефонов по коду или QR.
В зависимости от игры отдельный телефон выполняет роль игрового хоста или
ведущего, а TV показывает только общую, безопасную для всех информацию.

Конечный продукт — русско- и англоязычное web-приложение с независимыми
мобильными интерфейсами игроков, синхронным TV и набором готовых игр.

## Current architecture

- TASK-512: сервер непрерывно отсчитывает и рассылает игровые таймеры Квиза,
  Шпиона, обоих режимов Alias, Крокодила, Мафии и H2O. Переходы по истечении
  времени и задержки завершения Мафии / buzzer → playing выполняются сервером.
  Classic Alias при нуле ждёт решения по последнему слову; letter переходит
  к итогам без повторного начисления. В Who Am I игрового countdown нет.
  Перезапуск для активации TASK-512 и физический QA ещё не выполнялись.

- TASK-502: дневной таймер Мафии и таймеры «100 к 1» (buzzer, четвёртый раунд,
  Большая игра) отсчитывает и рассылает сервер без браузерных интервалов.
  H2O reset — отдельная host-команда; истёкшее время не восстанавливается
  устаревшими тиками. TV Мафии отображает дневной таймер. Серверная часть
  требует перезапуска dev-процесса; физический phone/TV QA ещё не проведён.
- Web: Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4, Geist,
  Framer Motion и собственный ru/en provider; зависимость `next-intl`
  установлена, но текущие production-компоненты используют локальные hooks.
- Realtime/backend: пользовательский Node HTTP server (`server.mts`) запускает
  Next и Socket.io 4 на одном порту; обработчики находятся в
  `src/server/socket-handlers.mts`.
- Хранение: комнаты, участники и часть room-state находятся только в памяти
  Node-процесса. Базы данных и постоянного серверного хранилища нет. Рестарт
  сервера уничтожает комнаты.
- Игровое состояние: сервер проверяет членство, текущую игру, actor/host,
  роль и фазу, а также удерживает канонический in-memory snapshot активной
  игры. Клиентские reducer-ы остаются UI-слоем. Reconnect/TV получают snapshot
  от сервера через `*:request-state`, причём приватные роли, слова, ответы и
  голоса фильтруются отдельно для каждого адресата. Подробнее — ADR 006.
- Identity: зарегистрированный mock-user хранится в `localStorage`; guest ID —
  в `sessionStorage`, поэтому разные вкладки/профили могут быть разными
  игроками. Первый room join выдаёт локально сохраняемый reconnect-token;
  новый socket не может занять существующий player ID без этого токена.
  Имя любого участника нормализуется до 10 символов до сохранения в комнате и
  проверки дубликатов; это единое правило для всех игр, phone и TV.
  Настоящей SMS-аутентификации пока нет.
- Locale: каждая новая комната использует server-owned русский язык независимо
  от языка браузера создателя. Каждый `room:state` синхронизирует русский язык
  лобби, direct join, всех семи phone-маршрутов и TV.
- Deployment: специальной production-инфраструктуры в репозитории нет. Из-за
  custom Socket.io server приложение требует долгоживущий Node-процесс, а не
  только serverless Next deployment.
- `mobile/` — отдельный Expo/React Native прототип. Он не содержит актуальных
  игровых экранов web-версии и сейчас не является основным клиентом.

Подробности архитектурных границ: `docs/decisions/001–006`.

## Important subsystems

- TASK-531: админка использует общий persistent черновик
  `data/admin-content-draft.json`. Кнопка дискеты атомарно сохраняет каталог в
  `content/game-content.json` с резервной копией в `data/content-backups/`.
  `/api/content` читает только опубликованный каталог; runtime загружает его
  при входе/смене маршрута и перед новым стартом Quiz / Who Am I. До первой
  публикации используются исходные TS-банки. Очередь/назначения активной игры
  остаются в прежнем server-owned snapshot; публикация не заменяет их.
  Новые тематические квизы, ru/en вопросы, персонажи и выбранные фоны входят
  в этот каталог. Положительный verdict с источниками автоматически отмечает
  точную версию вопроса проверенной; ручное утверждение хранится отдельно.
  TASK-532: повторная проверка пропускает подтверждённые Codex вопросы с
  источниками на UI и сервере; изменение формулировки/ответов снова требует
  проверки. Персонажи генерируются без автоматической ручной галочки.
  Ручные отметки персонажей и слов Alias/Crocodile/обоих режимов Spy хранятся
  в каталоге, но не выдаются через публичный API и не фильтруют игровые банки.
  Индексированные банки Alias/Crocodile/Spy этим изменением не заменяются.
  TASK-533: фон тематического квиза выбирается и сохраняется только как WebP.
  Библиотека админки исключает PNG-исходники в `public/backgrounds/sources/`.
  Новая генерация после одного модельного вызова сохраняет PNG в sources темы
  и автоматически создаёт игровой WebP quality 80 с теми же размерами.
  Существующие WebP URL сохранены; старые PNG-настройки требуют явного выбора
  WebP перед дискетой, без скрытой перезаписи черновика.
  TASK-534: при неточности factcheck может предложить полное ru/en исправление
  с четырьмя ответами, правильным вариантом и отдельными источниками.
  Кнопка «Исправить» применяет сохранённое подтверждённое предложение к той же
  версии вопроса в черновике; новая версия получает source-backed verified
  signature и пропускается в следующих проверках. Публикация — через дискету.
  Любая правка и новая проверка сбрасывают прежнее ручное утверждение.
  TASK-537: проверка Quiz работает только с русским текстом и хранит явную
  область `scope=ru`; английский текст в модель не отправляется и не
  перезаписывается исправлением. Русская проверка снимается правками
  `questionRu`, русских ответов или `correctIndex` и переживает правки
  английского; старые двуязычные проверки без области сохраняют прежнюю полную
  подпись. Fact-check использует меньшую модель `gpt-5.6-terra` с
  `ADMIN_CODEX_FACTCHECK_MODEL` и без фиксированного 3-минутного дедлайна;
  остальные текстовые и image-генераторы не меняются. Один запрос проверки — 2
  вопроса.
  TASK-538: создание вопросов, русская fact-check проверка и отдельный
  английский перевод работают через persistent последовательную очередь
  `data/admin-content-jobs.json`. Задания показывают прогресс, переживают
  обновление страницы и после перезапуска сервера возобновляются при следующем
  обращении к очереди; отмена останавливает работу после текущего блока.
  Вопросы имеют видимый lifecycle от черновика до публикации, тематические
  квизы — собственный профиль проверки, а проверка не повторяется для
  неизменённой подтверждённой русской версии. До модельного вызова интерфейс
  показывает модель, число запросов и ориентир времени.
  Локальный quality-анализ без модели ищет точные/похожие дубли, одинаковые и
  подозрительные по длине ответы, слишком длинный текст и отсутствующий
  перевод. Доступны массовые действия, отдельный перевод после RU-проверки,
  health-dashboard, content preview и история последних 30 снимков каталога с
  восстановлением отдельного вопроса. Очередь и история локальны одному Node-
  процессу/файловой системе и не предназначены для multi-node deployment.
  TASK-539: проверка Quiz запрашивает структурированный JSON-ответ локального
  Codex CLI. Повреждённый ответ не утверждает вопросы и не показывает сырую
  ошибку парсера; предыдущие обработанные блоки очереди сохраняются. Реальная
  повторная проверка модели после изменения ещё не проводилась.
  Browser QA и отдельное свежее review TASK-531 ещё не выполнены.

- `server.mts`, `src/server/socket-handlers.mts` — комнаты, присутствие,

## Game modes / features

### Quiz — DONE

Для всех квизов темы `harry-potter` канон — восемь основных фильмов Harry Potter
(2001–2011). При расхождении с книгой правильным считается ответ из фильма.
Книги и расширенные материалы не подтверждают ответы; правило применяется к
проверке, предлагаемому исправлению, замене и генерации. Проверки без policy
`harry-potter-films-v1` требуют повторной проверки и не допускают применения
старых предложений исправления / ручного утверждения без нового film factcheck.

Для всех тематических квизов `marvel` канон — фильмы и сериалы MCU от Marvel
Studios. Комиксы, игры и экранизации вне MCU не подтверждают ответы. Правило
применяется к проверке, исправлению и генерации; дополнительные профили могут
сужать тему или период, но не расширять канон за пределы MCU. Проверки без policy
`marvel-mcu-v1` требуют повторной проверки; старые предложения исправления и
ручное утверждение блокируются до новой проверки по MCU.

Общий квиз: сложность + тема. Специальные квизы: Гарри Поттер #1 и Marvel #1
с отдельными банками вопросов и тематическими фонами. Телефоны отвечают, TV
показывает вопрос/результаты; состояние поддерживает resync.

### 100 к 1 — DONE

Команды, капитаны, 4 раунда, страйки, передача банка, раунд «Наоборот», Большая
игра и финал. Отображаемый диапазон в лобби: 4–10.

### Crocodile — DONE, design accepted

Индивидуальная гонка до 20 слов: каждый 60-секундный ход один игрок объясняет,
свайп вправо даёт ему +1, свайп влево пропускает слово без штрафа. Достижение
20 очков запускает финальный круг: текущий игрок доигрывает ход, затем ход
получают все оставшиеся участники раунда. После полного круга побеждает игрок
с наибольшим счётом; итог может быть выше 20. Диапазон игроков: 2–10.
Остальные игроки угадывают вслух, текстового ввода ответа нет. Удалённые
`croc:guess-attempt` и `croc:correct` не восстанавливать.

TASK-518: при нуле сервер переводит ход в `turnResult`, сохраняя объясняющего
и число угаданных за ход слов. На его телефоне — итог и «Продолжить»; остальные
телефоны и TV ждут подтверждения. Только завершивший ход игрок может продолжить
через серверную команду с номером хода. Затем следующий игрок получает ready,
либо открывается финал после последнего хода финального круга. Reconnect
восстанавливает итог; авто-перехода по времени и обхода через host sync нет.

### Spy — DONE, design accepted

Режимы «Угадывай» и «Нарисуй». Случайный порядок игроков, цепочка вопросов без
повтора адресата внутри круга, общий синхронизированный холст, обсуждение,
тайное голосование, последняя попытка шпиона и ручной judge при неточном ответе.
Основной таймер обоих режимов — 3 минуты. Один игрок может быть шпионом не более
двух назначений подряд. После обсуждения открывается тайное голосование; само
истечение таймера голосования не раскрывает шпиона — результат появляется после
голосов всех игроков. В briefing подтверждённая роль остаётся скрытой и повторно
показывается только удержанием. Отображаемый диапазон: 3–10.

### Mafia — DONE, design accepted

Обязательный ведущий выбирается отдельным этапом после сбора игроков. Он не
получает игровую роль, видит роли/решения и вручную переключает завершённые
этапы. Игровые роли: Мирный, Мафия, Дон, Шериф (`detective` в коде), Доктор,
Любовница, Маньяк.

Распределение по общему числу участников, включая одного ведущего:

- 5–6: 1 Мафия, остальные Мирные;
- 7: 2 Мафии, Шериф;
- 8–9: 2 Мафии, Шериф, Доктор;
- 10: 2 Мафии + Дон, Шериф, Доктор;
- 11–12: 2 Мафии + Дон, Шериф, Доктор, Любовница;
- 13–15: то же + Маньяк;
- 16–17: 3 Мафии + Дон, Шериф, Доктор, Любовница, Маньяк.

Первая ночь — знакомство Мафии без убийств и проверок (TASK-511).
Со второй ночи подтверждённый голос Мафии неизменяем. Ночь последовательна:
`Мафия + Дон → Любовница → Маньяк → Доктор → Шериф → проверка Дона`.
Отсутствующие/выбывшие роли пропускаются. Дон имеет финальное слово по жертве
Мафии. Любовница не может выбрать себя/одного игрока две ночи подряд и блокирует
последующие активные способности, но не уже состоявшийся выстрел Мафии; у Дона
блокируется только отдельная проверка Шерифа. Доктор не лечит себя и одного
игрока две ночи подряд. Шериф проверяет живого игрока; Дон может проверять и
выбывшего. Доктор, Шериф и дневной голос требуют подтверждения.

Дневное голосование начинается сервером после 60 секунд обсуждения и
поддерживает ничьи, повторное голосование, финальный выбор
«казнить/помиловать» и алиби Любовницы. При дневном исключении роль не
раскрывается; финальный экран может раскрыть роли. Диапазон: 5–17.

### Who Am I — DONE

Персонажи, вопросы «Да/Нет», серия ответов, ввод/оспаривание угаданного ответа,
judge и resync. На телефоне игрок не видит собственного персонажа, но видит
персонажей остальных, включая активного участника; подпись «Сейчас ходит» на
скрытой карточке активного игрока видит только он сам. Отображаемый диапазон:
3–12.

### Alias / «Угадай слово» — DONE, design accepted

- «Классика»: 4–10, две команды, 60 секунд; продолжение недоступно, пока все
  игроки не выбрали команду. Очки за ход: угаданные минус пропущенные.
- «На букву»: 2–10, каждый сам за себя, 90 секунд; объясняющий получает +1 за
  «Угадали», пропуск без штрафа, буква меняется между ходами.

Карточка смахивается вправо при угадывании и влево при пропуске; улетает только
верхняя карточка. Итог показывает числа и списки слов.
Classic и letter mode изолированы: изменение одного режима не должно менять
scoring или flow второго. В letter mode остальные игроки угадывают вслух без
текстового ввода, а `finishTurn` не начисляет очки повторно. Удалённые
`alias:guess-attempt`, `alias:correct` и старую guesser-scoring схему не
восстанавливать.

## Approved behavior

- TV/creator и телефонный game host — разные роли. Первый подключившийся
  телефон становится игровым хостом; owner комнаты может исключать игроков из
  лобби. Ведущий Мафии — ещё одна отдельная роль.
- TV никогда не раскрывает приватные роли, слова или персональные голоса до
  предусмотренного правилами момента.
- Секреты Мафии и Шпиона раскрываются удерживанием и немедленно скрываются при
  `pointerup`, cancel или потере фокуса.
- После `game:start` QR закрывается; новая комната создаётся с открытым QR.
- Новые/перезагрузившиеся клиенты должны запрашивать полный state; нельзя
  полагаться только на live-event, который мог быть пропущен.
- Новые телефоны во время активной игры не подключаются; существующие игроки
  могут reconnect.
- Guest identity должна оставаться независимой между вкладками/профилями.
- Все production-строки должны существовать на ru/en. Preview/dev-страницы
  могут быть только на русском.
- Не запускать браузерный QA без явного запроса пользователя. Запрос
  «КОД — N телефонов» означает N видимых отдельных Chrome-окон 390×844 с
  независимыми `user-data-dir`, а не вкладки.

## Approved visual decisions

- Квиз: **«Пульс эфира»** перенесён в production для телефонов и TV; эталонный
  flow находится на `/quiz-design-preview#pulse-screens`. Общий квиз использует
  синий фон направления, специальный сохраняет точное изображение темы под
  нейтральными полупрозрачными панелями. Диапазон — **2–10 игроков**. Mobile-
  рейтинг показывает 10 игроков одним вертикальным списком, TV — двумя
  колонками по пять начиная с пяти игроков (места 1–5 слева, 6–10 справа).
  TV-карточки компактные, без растягивания по высоте; до пяти игроков один
  столбец. TV использует отдельную шапку и центрированную сцену 16:9.
- Мафия: **«Закрытый клуб»**, эталон `/mafia-design-preview#club-full-flow`;
  тёмный фиолетовый клуб, латунь/вино, реальные изображения из
  `public/icons/mafia-roles/`. Не перерисовывать роли без отдельного запроса.
- Шпион: **«Оперативный центр»**, эталон
  `/spy-design-preview#operations-full-flow`. Production-дельты после макета
  обязательны: в шапках нет подписи «Оперативный центр», телефонная шапка не
  отделяется другим цветом, крупные смысловые заголовки имеют weight 400,
  линии рисунка чёрные, секретное слово в draw не показывается сверху. Кнопки
  отмены/очистки рисунка контрастны; кнопка раннего голосования видима ведущему,
  а кольцо и TV-wave таймера обсуждения анимируются.
- Alias: **«Карточная мастерская»**, эталон
  `/alias-design-preview#workshop-full-flow`; белые стопки карточек, независимое
  смахивание верхней карточки, фоновые летающие карточки на телефоне/TV,
  адаптивный размер длинных слов без побуквенного переноса. Буква режима «На
  букву» использует исходную форму с `opacity: 0.7`.
- Crocodile: **«Свайп-протокол»**, эталон
  `/crocodile-design-preview#concept-mocap`; красная колода одинаковых карточек,
  полноценный свайп верхней карточки, целые слова с автоуменьшением, прогресс
  до 20 только на TV и максимум 10 игроков в двух колонках.
- Эти дизайны завершены и приняты. Не делать их новый редизайн без явной
  команды.
- Для следующего редизайна: сначала изучить логику/цвет/иконки, затем отдельная
  preview-страница с несколькими заметно разными концепциями, после выбора —
  полный mobile+TV flow в реальных размерах, и только после явного утверждения
  интеграция в production.

## Technical debt

- Четыре неиспользуемые legacy render-функции Мафии дают lint warnings;
  production использует `render*Club`.
- `src/app/tv/[roomId]/[gameType]/page.tsx` и несколько game pages слишком
  монолитны; разделять только отдельной безопасной задачей с регрессом.
- Метаданные игр/диапазоны игроков дублируются (`games-config`, Lobby, admin) и
  уже расходятся. Нужен единый источник истины без изменения текущих
  утверждённых диапазонов.
- Есть базовая автоматизированная Socket.io reconnect-матрица для семи игр и
  unit-тесты privacy/reducers. Полный browser multiplayer regression всё ещё
  выполняется несколькими реальными окнами и пока не автоматизирован.
- Client-host authority и in-memory rooms ограничивают отказоустойчивость и
  горизонтальное масштабирование.
- Admin API и mock auth нельзя считать production-безопасными.

## Current focus

Production Квиза использует утверждённый **«Пульс эфира»** на телефонах и TV.
Статические проверки интеграции прошли; production build и полный
multiplayer/browser regression не выполнялись. При отдельном разрешении нужно
проверить countdown, обычный вопрос, промежуточный рейтинг и финал на телефонах
и TV, отдельный общий квиз с синим фоном и live-рейтинг с 10 игроками.
Работа над дизайном «100 к 1» остановлена и не должна продолжаться без нового
явного запроса. `/hundred-to-one-design-preview` сохраняется только как архив:
четыре анимированных концепта и старый baseline из 7 mobile- и 6 TV-макетов.
Редизайн production «100 к 1» не менялся; TASK-502 исправляет только таймеры.
Production «Кто я?» использует утверждённую **«Голубую пластилиновую ночь»**:
общий mobile/TV soft-3D design system с `#38bdf8`/`#0284c7`, 12 телефонными и
6 TV-состояниями. Игровые action-ы, scoring, permissions и resync сохранены;
TV не раскрывает догадку и персонажа во время оспаривания. Production Spy
сохраняет утверждённый «Оперативный центр» и актуальные правила из раздела
выше. Production Crocodile использует «Свайп-протокол» и гонку до 20 слов.
Browser/multiplayer QA после последних изменений Who Am I, Spy и Crocodile не
запускался и выполняется только по явному запросу. Каноническая очередь — в
`TASKS.md`.

## Context maintenance

После существенной задачи рабочий чат создаёт отчёт и выполняет
`/context-save`; общий системный чат затем:

1. обновить этот файл только если изменились архитектура, продуктовый статус,
   утверждённое поведение или важные ограничения;
2. обновить `TASKS.md`;
3. создавать/обновлять ADR только для долговременного решения;
4. удалять устаревшую информацию, а не накапливать хронологию.
