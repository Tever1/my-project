# Project Status

Этот файл оставлен как совместимый указатель для старых сессий и отчётов.

Актуальное состояние проекта находится в:

- [`PROJECT_CONTEXT.md`](./PROJECT_CONTEXT.md) — текущая архитектура, продуктовые
  решения, принятые дизайны, ограничения и известные риски;
- [`TASKS.md`](./TASKS.md) — только актуальные задачи;
- [`docs/decisions/`](./docs/decisions/) — долговременные решения и причины;
- [`docs/AGENTS_UPDATE_PROPOSAL.md`](./docs/AGENTS_UPDATE_PROPOSAL.md) — готовое
  обновление защищённого `AGENTS.md`, которое должен применить его владелец.

История выполненных изменений хранится в Git и номерных `codex-reports/`.
Не добавляйте сюда хронологический журнал.
