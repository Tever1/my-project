# TASK-542 — Выбор объёма массовой проверки Quiz

## Результат

Кнопка «Проверить список» открывает окно выбора количества. Введённое целое число от 1 до количества оставшихся вопросов добавляет в очередь первые N ещё не проверенных вопросов текущего списка в исходном порядке. Кнопка «ВСЕ ОСТАВШИЕСЯ» добавляет весь остаток. Окно заранее показывает число модельных запросов: один запрос на два вопроса. Без выбора объёма модель не запускается.

Уже подтверждённые вопросы и вопросы в активных заданиях проверки исключены из остатка. Повторное нажатие во время отправки не создаёт второе задание. Проверка отдельного вопроса сохраняет прежнее подтверждение расхода лимита.
