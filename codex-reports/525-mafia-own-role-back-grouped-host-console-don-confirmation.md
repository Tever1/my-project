# TASK-525 — Мафия: рубашка карты, группировка пульта и подтверждение Дона

Дата: 2026-09-13. Реализовано локально по пяти запросам и трём скриншотам пользователя.

## Результат

- Справа от утреннего заголовка на телефоне игрока — рубашка собственной карты. Оригинальный SVG: тёмный фиолетовый, латунные рамки и ромбы, монограмма M. По нажатию открывается исходная крупная MafiaRoleCard через существующий native dialog. Кнопка не содержит названия роли; изображение лица появляется только после нажатия. Закрытие кнопкой, Escape, фоном, blur/скрытием страницы сохранено. Ведущий без роли рубашку не получает.
- Дневная сводка голосов ведущего сгруппирована по цели: слева выбранный игрок / Казнить / Помиловать, справа список голосовавших через запятую. Новая строка появляется при первом голосе за цель. Данные остаются приватными для ведущего.
- Панель «Все роли · пульт ведущего» сгруппирована по роли: одна миниатюра и название слева, имена справа через запятую. Имя выбывшего зачёркивается отдельно, живые имена той же роли сохраняют контраст. Длинные списки переносятся без truncate.
- Подсказка про выбор цели, индикаторы семьи и последнее слово Дона удалена из production actionPanel Мафии в ru/en; индикаторы и выбор семьи сохранены.
- Отдельная проверка Дона сначала выбирается локально, затем Назад/Подтвердить. Только подтверждение отправляет don-check-sheriff и отражается у ведущего. Клиент и сервер запрещают повторную замену подтверждённой проверки. Цели живые/выбывшие, запреты первой ночи, себя, блокировки и чужого actor сохранены. Общий голос Дона за жертву уже подтверждался вместе с Мафией.
