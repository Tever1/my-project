## Реализованные анимации

1. Макет начинается с трёх закрытых слоёв, поэтому эффект теперь виден с нуля.
2. Каждое «Да» плавно уводит следующий слой в сторону; символы внутри
   перестраиваются. «Нет» возвращает все слои.
3. Смена `ход → ввод → судья → расшифровка → финал` использует короткие
   enter/exit-переходы с opacity, translate и blur.
4. При верной догадке стекло расходится, а «ЧЕБУРАШКА» собирается по одной букве;
   затем появляется счёт.
5. TV автоматически дважды проигрывает цикл раскрытия трёх слоёв и показывает
   staggered-вход рейтинга.
6. Кнопка «Повторить анимации» перемонтирует mobile и TV demo.
7. CSS `prefers-reduced-motion` и `useReducedMotion()` отключают значимое
   движение для пользователей с соответствующей системной настройкой.

### Emil — restraint and speed

- Частые действия `Да / Нет` используют короткую реакцию `180ms`.
- Перемещение слоёв выполнено state-driven CSS transitions, поэтому клики можно
  прерывать и быстро менять направление.
- Более длинные эффекты оставлены только для редкой расшифровки и preview-demo.

### Jakub — production polish

- Все крупные смены экранов получили opacity + translate + blur; exit короче
  и спокойнее enter.
- Стекло и рейтинг входят последовательно без вспышки до animation delay.
- Слои используют кастомную кривую `cubic-bezier(.32,.72,0,1)` без bounce.

### Jhey — selective delight

- Расшифровка собирает имя из отдельных букв с небольшим stagger.
- TV демонстрирует идею автоматически, а replay позволяет повторить момент.
- Возможность для будущей итерации: отдельный звук стекла и тактильная отдача;
  в preview они намеренно не добавлялись.

### Accessibility and performance

- Анимируются только `transform`, `opacity`, `filter` и `clip-path`.
- `will-change` ограничен тремя интерактивными слоями.
- Автоматические циклы конечны; бесконечной крупной анимации нет.
- Reduced motion поддержан и на CSS-, и на React-уровне.
