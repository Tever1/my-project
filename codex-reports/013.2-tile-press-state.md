## Резюме (TL;DR)

В `function Tile` заменил `whileTap` на явный `pressed` state для pointer и keyboard press feedback. Mouse press теперь управляет `scale: 0.92` через pointer handlers, Enter/Space включает press и сбрасывает его через короткий timer, чтобы эффект был виден даже если глобальный Enter-handler сразу переводит фокус на CTA.

Статус partial только из-за проверок: общий `npm run lint` падает на существующих ошибках вне whitelist, а `npm run build` упал на Turbopack sandbox error `Operation not permitted`.
