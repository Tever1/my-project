# TASK-539 — Надёжный формат ответа проверки Quiz

## Результат

Проверка вопросов в админке запрашивает у локального Codex CLI ответ по JSON-схеме через `--output-schema`. Оба пути русскоязычной проверки (постоянная очередь и прямой API) используют одну схему и согласованные валидные JSON-примеры в запросах. После ответа остаётся строгая проверка ID, статусов, HTTPS-источников и исправлений. Повреждённый или пустой ответ не утверждает вопросы и больше не показывает пользователю сырую ошибку `JSON.parse`.

Исходный сбой воспроизведён на повреждённом JSON с пропущенным разделителем. В сохранённом задании Marvel было обработано 4 из 10 вопросов; очередь уже умела продолжать с этого места, поэтому её логику не меняли. Живое задание не перезапускалось.
