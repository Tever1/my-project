# TASK-521 — Мафия: имя погибшего, крупные карты и подтверждение Любовницы

Дата: 2026-09-12. Реализовано локально; browser QA и отдельное review перед публикацией ожидаются.

## Результат

- Утренняя сводка телефона показывает только имена погибших, без роли и ролевых изображений. TV уже выводил только имена; новый TV diff для этого запроса не нужен. Дневное исключение также остаётся без роли.
- Сервер больше не раскрывает роль только на основании ночной смерти, в том числе в eliminated и снимке после reconnect. Личная роль, знание семьи и права ведущего сохранены. Завершённая партия по-прежнему раскрывает все роли — это отдельный финал, не сообщение о гибели.
- Видимые миниатюры ролей на телефоне открывают тот же MafiaRoleCard, что используется при стартовой проверке. Native dialog ограничен экраном, поддерживает закрытие кнопкой, Escape/фоном, сохраняет фокус внутри; при потере фокуса или скрытии страницы закрывается. Стартовый hold-to-reveal не изменён. На TV миниатюры остаются неинтерактивными.
- Любовница выбирает цель локально, затем подтверждает или возвращается к выбору. До подтверждения lover-visit не отправляется, ведущий не получает решение. После подтверждения сервер запрещает повтор/замену цели. Сохраняются запреты первой ночи, себя, мёртвой цели, одного игрока две ночи подряд. Подтверждённый выбор восстанавливается из снимка.
- Завершён предыдущий follow-up TASK-511: исходный список целей Мафии с индикаторами выбора семьи сохранён; mafia-select синхронизирует изменяемый предварительный выбор семье, mafia-vote отдельно фиксирует решение. TV/мирные не получают черновики. Нижняя правая подпись TV удалена. Эти изменения уже присутствовали в dirty tree при текущем запросе; повторно проверены вместе с новым flow.
