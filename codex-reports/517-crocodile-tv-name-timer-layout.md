# TASK-517 — Имя и таймер Крокодила на TV

По двум замечаниям к HGPYFH исправлен только ready/explaining-блок
`src/app/tv/[roomId]/[gameType]/page.tsx`.

## Причина и изменение

- Таймер имел фиксированную ширину до 480 px независимо от оставшегося места
  рядом с аватаром. Теперь колонка текста занимает остаток (`min-w-0 flex-1`),
  таймер имеет `w-full max-w-[480px]`, меньшие отступы и перенос метки/цифр
  при нехватке места. Между аватаром и текстом оставлено 20–24 px.
- Имя использовало truncate и шрифт до 144 px. Теперь переиспользуется FitText:
  максимум 64 px, уменьшение по измеренной ширине, без многоточия; перерасчёт
  при смене имени, размера контейнера и загрузке шрифта.
- Игровые часы, протокол, таблица игроков, телефон и другие игры не менялись.
- Существующие dirty-изменения TV (Мафия/Alias) сохранены. FitText не изменён.
- Подход emil-design-eng применён к размерам и отступам без нового дизайна.

## Дополнение — постоянный цвет игрока

По замечанию к AP8Y7L цвет полосы назначается по ID в серверном playersOrder
до сортировки рейтинга. Рейтинг по-прежнему сортируется по очкам, но смена
места больше не меняет цвет игрока. Все состояния используют общий racePanel.
Для ID вне игрового порядка предусмотрен отсортированный fallback.

фактического блока построения рейтинга подтвердила 10 разных цветов и их
сохранение при обратном рейтинге, изменении порядка room players и отсутствии
игрока в room players при сохранённом игровом snapshot. Browser QA не проводился;
сервер не перезапускался, игровая логика не менялась.
