# TASK-509: исправления четырёх переходов H2O из TASK-508

## Результат

- Комнатный game host может выполнить title → buzzer («Начать игру»), даже
  когда другой игрок выбрал роль ведущего. Разрешение ограничено этим
  переходом и существующим whitelist стартового snapshot.
- Подтверждения капитанов принимаются как вклад собственной команды
  отправителя. Сервер игнорирует присланные копии чужой команды, объединяет
  канонические captains/captainConfirmed и сам переводит всех в teamNames.
- Аналогично объединяются подтверждения названий; после двух подтверждений
  сервер переводит всех в title независимо от устаревшего клиентского флага.
- «Пропустить» недоступно без двух капитанов; сервер дополнительно отклоняет
  этот переход, если капитаны не принадлежат соответствующим командам.
  Обычное подтверждение обоих капитанов по-прежнему автоматически продолжает
  игру. Автоматическое назначение капитанов не добавлено.
