# Preview-first visual baselines

## Context

Прямой редизайн production-экранов приводил к расхождению ожиданий и логики.
Для Мафии, Шпиона и Alias пользователь сначала выбирал концепцию, затем полный
flow телефона/TV, и только после этого разрешал интеграцию.

## Decision

Новый редизайн выполняется в три шага:

1. изучение текущей логики, цветов и доступных иконок;
2. несколько заметно разных концепций на отдельной preview-странице;
3. выбранная концепция разворачивается во все реальные mobile+TV состояния и
   только после явного утверждения переносится в production.

Утверждённые baselines:

- Mafia — «Закрытый клуб»;
- Spy — «Оперативный центр»;
- Alias — «Карточная мастерская».

Production-правки, явно принятые после preview, имеют приоритет над исходным
preview (перечислены в `PROJECT_CONTEXT.md`).

## Reason

Preview отделяет визуальное решение от игровой логики, позволяет сравнить
направления и снижает риск неполного буквального переноса.

## Alternatives

- Сразу менять production — отвергнуто из-за трудного сравнения и риска
  повредить flow.
- Наложить только новый фон/CSS на старую структуру — для Spy не передавало
  утверждённую композицию; потребовались отдельные структуры каждой фазы.

## Consequences

- Preview не должен содержать production game logic.
- Нельзя «улучшать» принятый дизайн по вкусу исполнителя.
- Реальные размеры, пропорции, анимации и privacy-состояния являются частью
  утверждения.
