# Owner, game host and Mafia moderator are separate roles

## Context

Экран, создавший комнату, часто является TV и не должен автоматически играть.
Одновременно нужны права управления комнатой, технический game host и отдельный
ведущий Мафии.

## Decision

- `ownerId` — создатель комнаты; может исключать игроков в лобби.
- `gameHostPlayerId`/`hostId` — телефонный игрок, управляющий общим flow игры;
  первым становится первый подключившийся телефон, роль можно передать.
- `mafiaHostPlayerId` — обязательный ведущий Мафии, выбранный game host на
  отдельном экране. Он исключается из раздачи ролей, видит решения и вручную
  переводит игру между завершёнными фазами.
- TV (`role: tv`) никогда не является подходящим телефонным host.

## Reason

Разделение позволяет TV оставаться общим экраном, владельцу управлять комнатой,
а Мафии иметь постоянного живого ведущего без игровой роли.

## Alternatives

- Сделать создателя/TV ведущим — отвергнуто: TV не является личным устройством.
- Автоматически назначать ведущего Мафии — отвергнуто: пользователь утвердил
  явный выбор на отдельном этапе.
- Встроить отдельный статичный «пульт» вне flow — отвергнуто: пульт ведущего
  меняется вместе с текущей фазой игры.

## Consequences

- Нельзя сводить эти ID в одно поле без миграции permissions и UX.
- Server actions Мафии должны проверять выбранного ведущего, а actor-actions —
  фактического отправителя.
- Lobby kick остаётся правом owner, а не любого host.
