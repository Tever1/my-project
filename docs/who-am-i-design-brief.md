# ТЗ на редизайн игры «Кто я?» (Who Am I)

Party Games Hub — party-игра, скачай контекст ниже перед началом.

---

## 0. Контекст проекта (для дизайн-агента без доступа к остальному репо)

**Party Games Hub** — мультиплеерный веб-хаб вечериночных игр,
host-authoritative архитектура. Игроки заходят с телефонов по QR-коду,
у комнаты есть общий экран — телевизор/ноутбук с большим дисплеем
(«игровое поле»), который подключает хост.

**Design DNA:** PS5 Home Screen × iOS 26 Liquid Glass. Матовое стекло
(`backdrop-blur`), крупные скруглённые углы, soft-shadows, приглушённая
премиальная база + яркий per-game акцентный цвет. Spring-анимации
400–600ms (Framer Motion), не резкие. Никаких стандартных эмодзи в
финальном UI — только кастомные плоские SVG line-иконки (кандидаты уже
готовы, см. раздел 6).

**Уже отредизайнены в этом языке** (можно смотреть как референс
визуального языка и уровня качества): Crocodile, Spy, Alias, частично
Mafia. «Кто я?» — следующая в очереди, **сейчас самая недоделанная игра
в проекте**: у неё нет отдельного TV-экрана вообще (см. раздел 2.2).

**Стек:** Next.js 16 (App Router) + TypeScript + Tailwind CSS v4 +
Framer Motion + Socket.io (кастомный сервер, host-authoritative) +
next-intl (ru/en, двуязычность обязательна для каждой строки).

**Два интерфейса на одну игру:**
- Мобильный — `src/app/game/[roomId]/who-am-i/page.tsx` (у каждого
  игрока свой телефон).
- TV / «игровое поле» — `src/app/tv/[roomId]/[gameType]/page.tsx`
  (общий экран, видят все одновременно).

## 1. Механика игры (контекст для дизайнера — что вообще происходит)

Каждому игроку тайно присваивается персонаж/личность (например,
«Гарри Поттер», «Билли Айлиш» — список персонажей уже есть в
`WHO_AM_I_CHARACTERS`). **Ключевая механика:** игрок НЕ видит своего
персонажа — его видят и знают все ОСТАЛЬНЫЕ игроки. Задача — угадать,
кто ты, задавая вслух вопросы с ответом «Да»/«Нет» другим игрокам
(ответы произносятся голосом, в приложении не набираются).

Ход по кругу:
1. У текущего игрока есть выбор: **«Дальше»** (передать ход следующему,
   засчитав, что задан вопрос) или **«Я знаю!»** (открыть поле ввода и
   написать угаданного персонажа).
2. Чем МЕНЬШЕ вопросов потребовалось до угадывания — тем больше очков
   (100 → 10 по убывающей шкале, см. `calculateScore`).
3. Угадавший игрок больше не участвует в ходах (наблюдает), его
   персонаж раскрывается всем (включая ему самому).
4. Игра идёт пока не угадали все, либо хост завершает её вручную в
   любой момент.
5. Финал — таблица результатов (места 1/2/3 + очки) и список «кто кем
   был».

**Важно для дизайна:** сама механика (кто угадывает, кто ходит, кто
сколько вопросов задал) уже реализована и работает — редизайн НЕ должен
менять игровую логику/socket-события, только визуал и информационную
архитектуру экранов. Если в процессе дизайна захочется добавить новую
фичу (например, таймер на ход, звуковой сигнал смены хода, анимацию
раскрытия персонажа) — это ОТДЕЛЬНОЕ обсуждение, помечай такие идеи явно
как «предложение», не встраивай молча.

## 2. Экраны

### 2.1 Мобильный экран (телефон игрока)

Файл: `src/app/game/[roomId]/who-am-i/page.tsx`. Обёрнут в
`<GameLayout>` (общий шапка+фон+scoreboard-компонент для всех игр).

**Фаза `lobby`** (ожидание старта):
- Карточка: заголовок игры, счётчик игроков в комнате, бейджи всех
  игроков (никнейм + звёздочка у хоста).
- У хоста — кнопка «Начать игру» (disabled если < 2 игроков).
- У остальных — «дышащий» индикатор ожидания (`BreathingPlaceholder`,
  уже есть как компонент, переиспользуется всеми играми).

**Фаза `playing`** (основной экран):
- Карточка «Сейчас ходит» — имя текущего игрока, либо «Ваш ход!» для
  себя. Подсказка-инструкция под ним, если ход твой.
- **Таймер хода (новая функция, см. раздел 2.2 «Таймер хода»)** — виден
  ВСЕМ игрокам рядом с карточкой «Сейчас ходит», не только активному
  (вся комната видит обратный отсчёт). Визуальная тревога в последние
  5 секунд (цвет/пульсация).
- Список ВСЕХ игроков с их персонажами:
  - Каждому игроку виден персонаж всех остальных.
  - Свой персонаж скрыт как «???», пока не угадан.
  - Текущий ходящий подсвечен (сейчас — фиолетовая заливка/рамка +
    указатель-эмодзи 👉, ЗАМЕНИТЬ на иконку из набора, см. раздел 6).
  - Угадавшие — приглушены (`opacity-50`), персонаж раскрыт с галочкой.
- Уведомление о последней попытке угадать (правильно/неправильно) —
  всплывающая карточка с эмодзи 🎉/❌ (заменить на иконки), именем и
  текстом попытки.
- Управление для текущего игрока (если ещё не угадал): кнопка «Дальше»
  (нейтральная) + «Я знаю!» (акцентная), либо (после клика «Я знаю!»)
  поле ввода ответа + «Угадать!»/«Отмена».
- Для НЕ текущего игрока — текст-подсказка «Ждите свой ход. Отвечайте
  на вопросы Да/Нет».
- Для игрока, который уже угадал — карточка «Вы уже угадали» +
  показ своего персонажа.
- У хоста — кнопка «Завершить игру» (danger).

**Фаза `finished`**:
- Карточка с трофеем 🏆 (заменить на иконку), заголовок «Игра
  окончена!».
- Таблица результатов: место (🥇🥈🥉/номер → заменить на иконку
  медали с цветовым кодом ранга, как сделано в Alias/Crocodile), имя,
  персонаж (+пометка «не угадал», если применимо), очки.
- Список «Все персонажи» — кто кем был, отдельным блоком.
- У хоста — кнопка «Играть снова».

### 2.2 TV / «игровое поле»

Файл: `src/app/tv/[roomId]/[gameType]/page.tsx`, ищется по
`gameType === 'who-am-i'`.

**ТЕКУЩЕЕ СОСТОЯНИЕ (важно): выделенного блока НЕТ.** Игра сейчас
проваливается в GENERIC-фоллбэк (используется для игр без кастомного
TV-рендера) — просто шапка с иконкой/названием, список игроков-плашек и
текст «Игра идёт — смотрите на телефонах!». Это по сути заглушка.

**Задача редизайна — создать полноценный TV-рендер**, как у остальных
6 игр (Crocodile/Spy/Alias/Mafia/Quiz/100-к-1 уже имеют кастомные
TV-блоки в этом же файле — можно смотреть как образец структуры:
`GameSurface` с фоном, HUD-шапка со scoreboard, full-screen контент по
фазам, `AnimatePresence` переходы).

Ниже — конкретное предложение макета по фазам. Строго в рамках
СУЩЕСТВУЮЩЕГО функционала: TV подписывается на тот же
`WhoAmIGameState`, который уже транслируется по сокету
(`characters`, `turnOrder`, `currentTurnIndex`, `guessedPlayers`,
`questionsAsked`, `scores`) — новых socket-событий и полей состояния
не требуется, только рендер того, что уже есть.

#### lobby

- Центр экрана: крупная иконка игры (`profile`, силуэт+«?», акцент
  `#38bdf8`) + заголовок «Кто я?» + короткий подзаголовок-инструкция
  в одну строку («Угадай, кем тебя назначили — задавай вопросы
  Да/Нет»).
- QR-код + код комнаты для входа (тот же паттерн, что уже есть в
  других TV-блоках — компонент `qrOverlay`, переиспользуется как есть).
- Ряд карточек подключённых игроков (никнейм + бейдж хоста), просто
  список — то же, что сейчас, без изменений логики.

#### playing — главный «зрелищный» экран

Верхний HUD (тонкая стеклянная полоса, как в остальных играх):
- Слева — иконка+название игры.
- По центру — крупно: «Сейчас ходит: {имя}».
- Справа — прогресс раунда: «Угадали: {guessedPlayers.length} из
  {turnOrder.length}».

**Layout выбран: «активный крупно + мини-ряд остальных»** (не сетка
одинаковых карточек для всех — при 8-10+ игроках она нечитаема
издалека).

- **Центр экрана — одна большая hero-карточка активного игрока**:
  никнейм крупно, круговой таймер хода вокруг/рядом (см. «Таймер
  хода» ниже), персонаж — **замаскирован** (см. «Маскировка своего
  хода»), счётчик «Вопросов задано: {questionsAsked[currentPlayerId]}»
  под именем.
- **Под hero-карточкой — компактный горизонтальный ряд остальных
  игроков** (`turnOrder` минус активный), мини-пилюли: никнейм +
  маленькая иконка статуса (`check` приглушённо-зелёным, если уже
  угадал; ничего, если просто ждёт своего хода). Персонаж в мини-ряду
  **не показываем** — там мало места, а разглядывать чужих персонажей
  с TV не критично для игры (каждый всё равно спрашивает только про
  свой ход). Если ряд не помещается по ширине при большом числе
  игроков — сжимать шрифт/паддинги пилюль (тот же приём, что и в
  Alias TV finished), не скроллить.

**Маскировка своего хода (закрывает вопрос «подглядывание с TV»):**
персонаж активного игрока на hero-карточке скрыт (затемнённый/блюрный
плейсхолдер с иконкой `profile`), пока не выполнено одно из двух
условий: игрок либо угадал (тогда раскрывается), либо его ход
завершился — по таймауту или через «Дальше»/угадывание
(`currentTurnIndex` увеличился, он больше не активный, дальше
показываем как обычного игрока в мини-ряду). Чистый рендер-condition
на клиенте, доп. серверной логики не требуется.

**Таймер хода (НОВАЯ функция — не в текущем функционале, требует
серверной логики, не только дизайна):**
- Круговой таймер (тот же визуальный паттерн, что уже реализован в
  Alias/Spy TV — SVG-круг с закрашивающейся дугой, viewBox 260,
  цвет = акцент игры `#38bdf8`, в последние 5 секунд — тревожный
  красный + пульсация/shake, см. Design DNA «Фаза G — In-game polish:
  таймеры с visual urgency»).
- Показывается ОБОИМ экранам одновременно — на TV вокруг hero-карточки
  активного игрока, на мобильном — рядом с карточкой «Сейчас ходит»
  у ВСЕХ игроков (не только у активного — так вся комната видит
  обратный отсчёт, это часть напряжения игры).
- **Длительность и поведение по истечении — на усмотрение
  реализации** (продакт не высказал предпочтения); по умолчанию
  предлагается использовать уже принятый в проекте паттерн
  (Alias letter mode: 30 секунд, автопередача хода — эквивалент клика
  «Дальше», т.е. вопрос засчитывается как заданный) — но это
  предположение, не финальное решение, подтвердить перед реализацией.
- Технически: нужен новый серверный таймер по аналогии с Spy
  (`timerLeft`/`timerRunning`, broadcast раз в секунду через
  `who-am-i:sync` или расширение существующего `sync-state`) — это уже
  не чистый дизайн, а фича, требующая изменений в
  `src/app/game/[roomId]/who-am-i/page.tsx` (обработка таймера) и,
  возможно, в состоянии `WhoAmIGameState` (добавить `timeLeft`).
  Помечаю явно: **реализацию таймера нужно обсуждать отдельно с
  Codex/Claude в этом чате, «Claude Design» отвечает только за то, как
  таймер должен ВЫГЛЯДЕТЬ**.

Реакция на попытку угадать — полноэкранный overlay на несколько секунд
(AnimatePresence, cross-fade):
- Правильно → крупная иконка `celebrate`, имя игрока, текст
  попытки, акцентный цвет игры.
- Неправильно → крупная иконка `cross`, приглушённый красный, текст
  попытки.
Использует те же данные, что уже приходят в `lastGuessResult` на
мобильном (`type: 'guess'` action) — TV слушает то же событие
`game:action`, доп. broadcast не нужен.

#### finished

**Reveal выбран: по очереди (шоу-формат), не сразу.** Персонажи всех
игроков раскрываются последовательно, от последнего места к первому
(как в телешоу «а на третьем месте...»), с паузой между карточками.
Данных для этого достаточно уже сейчас (`scores`, `guessedPlayers`,
`characters`, `turnOrder`) — реализуется через `AnimatePresence` +
`staggerChildren`/задержку по индексу, доп. серверной логики не
требуется, это чистая клиентская анимация.

Порядок экрана:
1. Заголовок «Игра окончена!» появляется первым.
2. Карточки игроков раскрываются одна за другой СНИЗУ ВВЕРХ по
   таблице результатов (сначала последнее место, последним — победитель)
   — каждая карточка переворачивается/проявляется (flip или fade+scale,
   на усмотрение реализации) с интервалом ~0.4-0.6с, показывая имя,
   персонажа, очки; если не угадал — пометка (как на мобильном,
   `не угадал`).
3. Топ-3 после раскрытия дополнительно подсвечиваются иконкой `medal`
   с цветовым кодом ранга (золото/серебро/бронза через `color`, как
   уже сделано в Alias/Crocodile TV-финале) — крупнее остальных,
   финальный акцент на победителе.

**Важно для 10+ игроков:** при большом составе полная последовательная
анимация (0.5с × 10+ карточек = 5+ секунд ожидания) может быть долгой
— приемлемо для финального экрана (одноразовое событие, не мешает
геймплею), но стоит держать интервал ближе к 0.3-0.4с при большом
числе игроков, а не к 0.6с, чтобы шоу не затягивалось.

Общий тон — см. Design DNA раздел «Фаза H — TV mode glow-up» в
основном CLAUDE.md проекта (`«Включи на большом экране — и это станет
настоящим шоу»`).

**Тон/атмосфера для этой игры** (из общего плана дизайна проекта,
Фаза I «Per-game theming»): *Who Am I? — curious (любопытный), soft
fades* — мягкие, любопытствующие переходы, не резкие как у Мафии
(mystic) и не карнавальные как у Крокодила (playful). Детективно-
любопытный тон, но не тёмный/зловещий.

## 3. Функции / кнопки — полный список по экранам

| Экран | Фаза | Кнопка / контрол | Кому видна | Действие |
|---|---|---|---|---|
| Mobile | lobby | «Начать игру» | Хост | Раздать персонажей, начать раунд |
| Mobile | playing | «Дальше» | Текущий ходящий, ещё не угадал | Передать ход, засчитать вопрос |
| Mobile | playing | «Я знаю!» | Текущий ходящий, ещё не угадал | Открыть поле ввода ответа |
| Mobile | playing | «Угадать!» | Текущий ходящий, после «Я знаю!» | Отправить попытку угадать |
| Mobile | playing | «Отмена» | Текущий ходящий, после «Я знаю!» | Закрыть поле ввода, не тратя ход |
| Mobile | playing/finished | «Завершить игру» | Хост | Досрочно закончить раунд |
| Mobile | finished | «Играть снова» | Хост | Новый раунд, новая раздача персонажей |
| TV | lobby | — (нет кнопок, только QR/код) | все | — |
| TV | playing | — (зрительский экран, кнопок нет) | все | — |
| TV | finished | — (зрительский экран, кнопок нет) | все | — |

Кнопки уже стандартизированы дизайн-системой проекта — переиспользуй
эти варианты, не изобретай новые стили:
- `GlassButton variant="primary"` — главное действие (Начать игру,
  Я знаю!, Угадать!, Играть снова).
- `GlassButton variant="default"` — второстепенное действие (Дальше,
  Отмена).
- `GlassButton variant="danger"` — разрушительное действие (Завершить
  игру).
- Размеры: `size="lg"` для главной CTA на весь экран, `size="sm"`/`md`
  для второстепенных.
- Все кнопки — spring-анимация нажатия `whileTap scale 0.96` уже встроена
  в компонент, ничего дополнительно делать не нужно.

## 4. Цвета

Акцентный цвет игры (утверждён, уже в `src/lib/design/tokens.ts`):

```
who-am-i: accent #38bdf8 (sky blue / голубой), deep #0284c7
```

Референс-градиенты, уже добавленные для превью на `/design-tokens`
(секция «Кто я? · плоские иконки»), можно использовать как основу
фона/карточек:

```css
/* Тёмный фон (страница/GameSurface) */
linear-gradient(135deg, #071825 0%, #0a2d3f 30%, #0c2530 60%, #071825 100%)

/* Акцентная карточка (например подсветка текущего хода вместо фиолетовой) */
radial-gradient(110% 70% at 50% -5%, rgba(255,255,255,.22), transparent 55%),
linear-gradient(165deg, #38bdf8 0%, #0369a1 100%)
```

Текст на тёмном фоне — `#7dd3fc` (светло-голубой), текст на акцентной
карточке — `#f0f9ff` (почти белый с голубым оттенком).

**Важно:** сейчас в коде подсветка «текущий ход» и акцентные бейджи у
Who Am I используют ФИОЛЕТОВЫЙ (`purple-500`, `purple-300`) — это
несогласовано с утверждённой палитрой игры (голубой). При редизайне
заменить весь фиолетовый на голубой акцент игры.

## 5. Иконки (замена эмодзи)

8 эмодзи в текущем коде игры, для каждого уже подготовлен
SVG-кандидат — плоская line-иконка (viewBox 24, `stroke="currentColor"`),
превью живьём смотри на `/design-tokens` → секция «Кто я? · плоские
иконки (превью)»:

| Эмодзи | Где используется | Иконка-кандидат |
|---|---|---|
| ⭐ | Бейдж хоста в лобби | `star` |
| 👉 | Указатель «сейчас ход» в списке игроков | `pointer` |
| ✅ | Персонаж уже угадан (бейдж) | `check` |
| 🎉 | Правильная догадка / «вы уже угадали» | `celebrate` |
| ❌ | Неправильная догадка | `cross` |
| 🏆 | Заголовок экрана «Игра окончена!» | `trophy` |
| 🥇🥈🥉 | Места 1/2/3 в таблице результатов | `medal` (с цветовым кодом ранга — золото/серебро/бронза через `color`, как сделано в Alias/Crocodile TV-финале) |
| 🤔 | Иконка игры в шапке `GameLayout`/TV | `profile` (силуэт + «?») |

Иконки уже готовы технически (React-компоненты в стиле остальных игр,
`currentColor`), встраивание в сам код игры — отдельная задача ПОСЛЕ
того, как утвердим общий дизайн экранов по этому ТЗ.

## 7. Что НЕ входит в этот редизайн

- Игровая логика/socket-события (`who-am-i:*`) — не трогаем, только
  визуал существующих состояний. **Исключение — таймер хода** (раздел
  2.2): это единственная НОВАЯ функция в этом ТЗ, она требует
  серверных изменений, но её РЕАЛИЗАЦИЮ ведёт Claude/Codex в этом
  репозитории отдельно от визуального редизайна. От «Claude Design»
  нужен только внешний вид таймера (форма, цвет, состояние тревоги).
- Список персонажей (`WHO_AM_I_CHARACTERS`) — не трогаем.
- Формула очков (`calculateScore`) — не трогаем.
