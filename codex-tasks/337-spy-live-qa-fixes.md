## Цель

4 независимых фикса по live-QA от пользователя:
1. Надпись «Сейчас отвечает» → «Задаёт вопрос» (TV + мобильный).
2. Кнопка «Понятно, спрятать» на экране раздачи слова реально прячет
   слово (сейчас не прячет, только помечает игрока «готов»).
3. В режиме рисования — кнопка отмены последнего действия (undo), не
   только полная очистка.
4. На TV во время ЖИВОГО голосования (`phase === 'voting'`) не
   показывать, кто за кого голосует — только счётчик голосов.

### 2. Баг «Понятно, спрятать» не прячет слово

Сейчас (`src/app/game/[roomId]/spy/page.tsx`, экран `s.phase === 'dealing'`,
примерно строки 1024-1097): карточка со словом/ролью рендерится
БЕЗУСЛОВНО, независимо от того, нажал ли игрок «Понятно, спрятать»
(`myReadyInDealing`). Кнопка меняется на неактивную «Готов», но слово
над ней остаётся видимым — отсюда баг.

Исправление: обернуть блок карточки со словом/ролью (три ветки:
draw+spy, draw+civilian, guess+spy, guess+civilian — то есть всё
содержимое условия `s.mode === 'draw' ? (...) : isSpy ? (...) : (...)`,
строки ~1024-1077) в условие `!myReadyInDediling` (когда ЕЩЁ не нажал
готов — показывать слово как сейчас), и когда `myReadyInDediling === true`
— показывать вместо этого простую нейтральную заглушку-плейсхолдер,
например:

```tsx
<GlassCard className="spy-card p-6 text-center space-y-2">
  <SpyIcon name="hide" className="mx-auto h-10 w-10 text-white/40" />
  <p className="text-white/50 text-sm">
    {l('Слово спрятано', 'Word hidden')}
  </p>
</GlassCard>
```

(проверить точное имя переменной — в файле она может называться
`myReadyInDealing`, свериться по фактическому коду, не по опечатке в этом
ТЗ). Строка со счётчиком «X / Y посмотрели слово» (~1079-1081) и кнопки
ниже (~1083-1097) остаются как есть, без изменений.

### 3. Кнопка отмены последнего действия в режиме рисования

Сейчас `DrawCanvas` (тот же файл, строки ~28-122) поддерживает только
полную очистку (`onClear`/кнопка «Очистить»). Каждый мазок шлётся как
серия мелких отрезков через `onStroke` по мере движения пальца/мыши —
истории мазков нигде не хранится, только сырое рисование на canvas.

Добавить:
- Внутри `DrawCanvas`: `const groupsRef = useRef<DrawStroke[][]>([]);` и
  `const currentGroupRef = useRef<DrawStroke[]>([]);`.
- В `moveDraw` — помимо вызова `onStroke(...)` и `drawLine(...)`, также
  пушить сегмент в `currentGroupRef.current`.
- В `endDraw` — если `currentGroupRef.current.length > 0`, запушить его
  в `groupsRef.current` и обнулить `currentGroupRef.current = []`.
- Новая кнопка «Отменить» рядом с существующей «Очистить» (тот же
  верхний правый угол canvas, показывать только если `canDraw &&
  groupsRef.current.length > 0` — можно хранить булево в `useState` для
  реактивности кнопки, например `const [hasHistory, setHasHistory] =
  useState(false);`, обновлять в `endDraw`).
- По клику «Отменить»:
  1. `groupsRef.current = groupsRef.current.slice(0, -1);` (убрать
     последнюю группу),
  2. `clearAll()` (очистить локальный canvas),
  3. заново отрисовать все оставшиеся группы локально: `groupsRef.current.forEach(group => group.forEach(seg => drawLine(seg.x1, seg.y1, seg.x2, seg.y2)));`,
  4. вызвать новый проп `onUndo(groupsRef.current.flat())` — родитель
     ретранслирует остальным клиентам (см. ниже), обновить `hasHistory`.
- В `DrawCanvasProps` добавить `onUndo: (remainingStrokes: DrawStroke[]) => void;`.
- В месте использования `<DrawCanvas canDraw={isDrawer} onStroke={sendStroke} onClear={sendClear} />`
  (строка ~1160) добавить `onUndo={handleUndo}`, где `handleUndo`
  — новая функция рядом с `sendStroke`/`sendClear`:
  ```ts
  const handleUndo = useCallback((remainingStrokes: DrawStroke[]) => {
    sendClear(); // broadcast: все остальные клиенты чистят канвас
    remainingStrokes.forEach((stroke) => sendAction('spy:stroke', stroke));
  }, [sendClear, sendAction]);
  ```
  (переиспользуем существующие `spy:clear`/`spy:stroke` экшены — на
  стороне TV и других телефонов ничего менять не нужно, они уже умеют
  обрабатывать оба этих экшена).

### 4. Скрыть кто за кого голосует во время живого голосования (TV)

`src/app/tv/[roomId]/[gameType]/page.tsx`, блок `sp.phase === 'voting'`
(строки ~1568-1610): убрать ряд с аватарками проголосовавших —

```tsx
<div className="flex gap-1 min-h-6">
  {voters.map(voterId => (
    <div key={voterId} className="w-6 h-6 rounded-full bg-white/20 flex items-center justify-center text-xs">
      {spyGetName(voterId)[0]}
    </div>
  ))}
</div>
```

убрать целиком (вместе с переменной `voters`, если она после этого нигде
больше не используется в этом блоке — тогда убрать и её объявление,
строки ~1584-1586). Оставить только полоску-бар (`barPct`) и числовой
счётчик (`votesFor`) — это уже есть, не трогать. Метка «лидер» у
максимума голосов — тоже оставить, это не раскрывает КТО голосовал,
только текущий счёт.

**Важно:** блок `sp.phase === 'roundResult'` (после того как голосование
уже завершилось и раунд разрешён) — НЕ трогать, если там где-то
показываются голоса постфактum — это уже не «во время голосования», а
результат, раскрытие там нормально и не относится к этому багу.

## Открытые вопросы для Codex

- Нужно ли синхронизировать историю мазков (`groupsRef`) между
  клиентами при реконнекте/resync (TASK-335)? — **Нет**, вне рамок этого
  таска — история undo существует только локально у текущего рисующего
  на время его хода, это не часть синхронизируемого игрового состояния.
- Что если во время undo рисующий уже успел передать ход (`isDrawer`
  стал `false`)? — Кнопка «Отменить» и так скрыта когда `!canDraw`
  (тот же гейт, что и у «Очистить») — можно не обрабатывать отдельно.
- Нужно ли показывать иконку/анимацию при undo? — **Нет**, просто мгновенная
  перерисовка canvas, без лишних эффектов.
