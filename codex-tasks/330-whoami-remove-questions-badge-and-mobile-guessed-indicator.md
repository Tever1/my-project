# TASK-330: «Кто я?» — убрать бейдж «Вопросов задано» и индикатор угаданных с мобильного

**Тип:** simple (1 файл, механическая правка)
**Whitelist:** `src/app/game/[roomId]/who-am-i/page.tsx`
**НЕ трогать:** `src/app/tv/[roomId]/[gameType]/page.tsx` и любые другие файлы —
TV-индикатор угаданных (там уже есть ✅, строка ~2365) остаётся как есть.

---

## Часть 1 — убрать бейдж «Вопросов задано»

В `renderPlaying()` (блок «Controls for current player») есть два бейджа
рядом: `«Вопросов задано: N»` и `«Да» подряд: N/3`. Пользователь считает
первый избыточным — он дублирует смысл второго (оба растут вместе, пока не
передан ход). Убрать бейдж «Вопросов задано» полностью (JSX-блок с
`{l(\`Вопросов задано: ${myQuestions}\`, ...)}`), оставить только бейдж
«„Да" подряд: N/3». Если после удаления переменная `myQuestions` (или её
вычисление) больше нигде не используется — удалить и её объявление тоже
(не оставлять мёртвый код).

## Часть 2 — убрать индикатор «кто угадал» с мобильного экрана

В `renderPlayerCharacters()` (список персонажей) сейчас для угадавших игроков
(`isGuessed`) показывается: приглушение карточки (`opacity-50`) + бейдж
`✅ {имя персонажа}` вместо обычного бейджа с именем персонажа. Пользователь
хочет, чтобы этот статус «кто уже угадал» был виден **только на TV** («игровое
поле»), а на мобильном экране — убрать.

Убрать на мобильном:
- Условный класс `opacity-50` для угадавших карточек.
- Ветку `isGuessed ? <✅-бейдж> : ...` — угадавший игрок должен показываться
  так же, как обычный (не угадавший) игрок: обычный бейдж с именем его
  персонажа (`char?.[locale]`), без ✅ и без спец-стилизации.
- Сохранить остальную логику без изменений: свой персонаж всё ещё "???"
  (`isMe` ветка), подсветка текущего хода (`isCurrent`, 👉) — не трогать.
