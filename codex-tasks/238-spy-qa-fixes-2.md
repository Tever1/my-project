## Правки

### 1. Peek-бар «ТВОЁ СЛОВО» — уже в 2 раза
Файл: `spy/page.tsx`, `renderPeekBar`. Сделать блок примерно в 2 раза уже
(центрировать): на внешний контейнер бара добавить `mx-auto w-1/2 min-w-[200px]`
(или эквивалент, дающий ~половинную ширину по центру). Содержимое сохранить.

### 2. Убрать таймер с мобильного игрового поля
Файл: `spy/page.tsx`, фаза `playing`, `s.mode === 'guess'`. Убрать круговой
SVG-таймер (блок `<div className="flex justify-center"><div className="relative h-[84px] w-[84px]">…</div></div>`
с `<svg>` и подписью «твой ход/ход»). Таймер остаётся на TV. Карточку
«Твой ход» / «Сейчас отвечает» ОСТАВИТЬ. Логику таймера (отсчёт, авто-голосование)
НЕ трогать — убираем только визуал на телефоне.
Если после удаления остаётся неиспользуемый код (`timerRatio`, `timerOffset`,
`PHONE_TIMER_CIRC`) — убрать его, чтобы lint был чистым.

### 3. TV: убрать подпись про запуск раунда после завершения
Файл: `tv/[roomId]/[gameType]/page.tsx`, блок spy `roundResult`. Удалить
`<p>📱 Ведущий: запустить раунд {sp.currentRound + 1} →</p>`.

### 4. Кнопка результата раунда «▶ Раунд N» → «Новое слово»
Файл: `spy/page.tsx`, фаза `roundResult`, кнопка host для следующего раунда
(`onClick={nextRound}`, сейчас текст `▶ Раунд ${s.currentRound + 1}`). Заменить
текст на «Новое слово» / «New word». Логику (`nextRound`) НЕ менять.

### 5. Шпион: Enter в поле ввода = проверить слово
Файл: `spy/page.tsx`, фаза `spyGuess`, `<input>` для ввода версии шпиона.
Добавить `onKeyDown`: при `Enter` и непустом `guessInput.trim()` вызывать
`sendAction('spy:guess-try', { text: guessInput })`. Кнопку «Проверить» ОСТАВИТЬ
как есть (работает параллельно).

### 6. Убрать кнопку запуска таймера; таймер стартует автоматически
Файл: `spy/page.tsx`. Сейчас в фазе `playing` (в шапке-`GlassCard`) у host есть
кнопка «▶ Запустить таймер» (и текст «таймер на паузе»). Убрать эту кнопку и
текст-паузу из шапки (оставить только «Раунд N / категория»).
Таймер должен автоматически запускаться при переходе в `playing`:
- `startPlaying` (кнопка «Начать обсуждение» / «Начать рисование»): ставить
  `timerRunning: true` (сейчас `false`).
- В хендлере `spy:ready` авто-переход в `playing` (когда все посмотрели слово):
  тоже ставить `timerRunning: true`.
Это применимо к обоим режимам (guess и draw). Функцию `startTimer` удалить, если
она становится неиспользуемой.
