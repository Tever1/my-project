## Цель

Добавить второй проход в `scripts/strip-bg.mjs`: **flood-fill от углов**.
После удаления ахроматических светлых пикселей (текущая логика), запускаем
4-связный BFS со всех 4 углов изображения. Любой пиксель, который **соединён
через цепочку светлых пикселей с углом** и сам **достаточно светлый**, ставим
в alpha=0.

Это уберёт светло-жёлтый/почти-белый halo вокруг субъекта (например, мозга
в `quiz.png`), который не цепляется ахроматическим фильтром (у него spread
30-50 между каналами).

## Контекст

После TASK-005.1 в `quiz.png` остался светлый ореол:
- `[247, 239, 200, 255]` — пале-жёлтый halo (spread 47)
- `[254, 251, 201, 255]` — почти-белый с жёлтым оттенком (spread 53)

Сам субъект (мозг) — насыщенно-жёлтый:
- `[253, 210, 2, 255]` — основная масса (spread 251)
- `[196, 114, 0, 255]` — глубокая тень
- `[254, 243, 116, 255]` — highlights (spread 138)

Halo соединён с уже-прозрачными углами через светлые пиксели → flood-fill
от углов его съест, не дойдя до субъекта (потому что брайн насыщенный, его
пиксели не пройдут «light gate»).

## Шаги реализации

1. В `scripts/strip-bg.mjs` добавить новую константу:
   ```js
   const FLOOD_LIGHT_THRESHOLD = 180; // min(R,G,B) >= это значит "светлый достаточно для затопления"
   ```
   (НЕ путать с существующим `LIGHT_THRESHOLD = 220` для ахроматического шага.)

2. Добавить новую функцию `floodFillFromCorners(data, width, height)`:
   ```js
   function floodFillFromCorners(data, width, height) {
     const visited = new Uint8Array(width * height);
     const queue = [];
     let stripped = 0;

     const enqueue = (x, y) => {
       if (x < 0 || y < 0 || x >= width || y >= height) return;
       const idx = y * width + x;
       if (visited[idx]) return;
       visited[idx] = 1;
       queue.push(x, y);
     };

     // Seed from all 4 corners
     enqueue(0, 0);
     enqueue(width - 1, 0);
     enqueue(0, height - 1);
     enqueue(width - 1, height - 1);

     while (queue.length > 0) {
       const x = queue.shift();
       const y = queue.shift();
       const offset = (y * width + x) * 4;
       const r = data[offset];
       const g = data[offset + 1];
       const b = data[offset + 2];
       const a = data[offset + 3];

       const min = Math.min(r, g, b);

       // Flood crosses if pixel is already transparent OR is light enough
       const isTransparent = a === 0;
       const isLight = min >= FLOOD_LIGHT_THRESHOLD;

       if (!isTransparent && !isLight) continue; // hit subject — don't expand

       // If light and still opaque — make transparent
       if (!isTransparent && isLight) {
         data[offset + 3] = 0;
         stripped += 1;
       }

       // Expand to 4 neighbors
       enqueue(x + 1, y);
       enqueue(x - 1, y);
       enqueue(x, y + 1);
       enqueue(x, y - 1);
     }

     return stripped;
   }
   ```

3. В `processIcon()`, после `const stripped = stripBackgroundPixels(data);`
   добавить:
   ```js
   const haloStripped = floodFillFromCorners(data, info.width, info.height);
   ```

4. Обновить лог-строку чтобы показать оба числа:
   ```js
   console.log(`${filename}: ${info.width}x${info.height} ${sourceSpace} -> RGBA, ${stripped} achromatic + ${haloStripped} halo pixels stripped`);
   ```

## Ограничения и подводные камни

- **`queue.shift()` на массиве — O(n).** Для 1254×1254 это 1.5M элементов,
  shift каждого = O(n²). Для MVP пойдёт (займёт несколько секунд), но если
  будет тормозить — заменить на индекс-указатель `let head = 0;` с
  `queue[head++]`. **MVP — оставить shift, оптимизация потом если надо.**
- **4-связность достаточна.** 8-связность не нужна — она может «протекать»
  через диагональные anti-aliasing пиксели и съесть субъект.
- **Не менять `FLOOD_LIGHT_THRESHOLD`** — 180 это компромисс: ловит halo
  (`min ~200`), не ловит насыщенный жёлтый (`min ~2-50`). Если потом
  обнаружится что субъект задевает, Claude скорректирует на следующей
  итерации.
- **Память:** `Uint8Array(width*height)` для visited = ~1.5MB для 1254×1254.
  ОК.
