## Цель

Обновить логику определения фонового пикселя в `scripts/strip-bg.mjs`:
сейчас стрипается только чисто-белое (`R/G/B ≥ 240`), но ChatGPT image gen
зашивает в PNG **визуальную шахматку прозрачности** как реальные пиксели —
чередуя белые (RGB ~253) и серые (RGB ~232-239) квадраты. Серые клетки
проходят порог 240 и остаются видны.

Новая логика: пиксель считается фоном, если он **светлый и ахроматический**
(близкий к серому), а не «чисто белый».

## Контекст

Sample из `public/icons/games/mafia.png` (новая иконка, RGBA после
TASK-005):
- TL `[233, 232, 233, 255]` — серый квадрат шахматки, alpha=255 (виден)
- 25,25 `[253, 253, 253, 0]` — белый, уже прозрачный
- 50,50 `[238, 237, 237, 255]` — серый, виден
- center `[14, 8, 39, 255]` — субъект (тёмный фиолетовый)

Чисто увеличить порог до 220 нельзя — субъект имеет светлые highlights,
но они **цветные** (фиолетовые блики типа `[180, 160, 220]`), у них spread
между каналами большой. Шахматка же ахроматическая — `R ≈ G ≈ B`.

## Шаги реализации

1. В `scripts/strip-bg.mjs`:
   - Переименовать `WHITE_THRESHOLD = 240` в две константы:
     ```js
     const LIGHT_THRESHOLD = 220;   // min(R,G,B) >= это значит "светлый"
     const CHROMA_THRESHOLD = 15;   // max(R,G,B) - min(R,G,B) <= это значит "ахроматический"
     ```
   - Переименовать функцию `stripWhitePixels` → `stripBackgroundPixels`.
   - Логика: пиксель считается фоном если
     ```js
     const min = Math.min(r, g, b);
     const max = Math.max(r, g, b);
     if (min >= LIGHT_THRESHOLD && (max - min) <= CHROMA_THRESHOLD && a !== 0) {
       data[offset + 3] = 0;
       stripped += 1;
     }
     ```
   - Обновить лог-строку: `... pixels stripped` оставить как есть.
2. Всё остальное (структура файла, обработка списка, sharp pipeline) — не
   трогать.

## Ограничения и подводные камни

- **Не трогать threshold для чисто-белого.** Новая логика покрывает оба
  случая (белый: min=253, max-min=0; серый: min=232, max-min=2-3) — оба
  попадают под `min ≥ 220 && spread ≤ 15`.
- **Не добавлять CLI-флаги.** Threshold захардкожен.

  на следующей итерации**.
