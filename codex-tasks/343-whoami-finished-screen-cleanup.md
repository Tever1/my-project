## Шаги реализации

### 1. Убрать верхний HUD со счётом

Строка ~1099:
```tsx
showScoreboard={gs.phase === 'finished'}
```
Заменить на:
```tsx
showScoreboard={false}
```
(проп `scores` на строке ~1097 можно оставить как есть — он больше
никак не используется без `showScoreboard`, трогать не обязательно).

### 2. Убрать блок «Все персонажи»

В `renderFinished()`, строки ~1041-1059, убрать целиком блок:
```tsx
{/* Reveal all characters */}
<div className="border-t border-white/10 pt-4">
  <h3 className="text-white/50 text-sm mb-3">
    {l('Все персонажи', 'All Characters')}
  </h3>
  <div className="space-y-1">
    {gs.turnOrder.map((id) => (
      <div
        key={id}
        className="flex items-center justify-between gap-3 rounded-full border border-sky-300/15 bg-sky-400/5 px-3 py-1.5 text-sm"
      >
        <span className="text-white/70">{playerName(id)}</span>
        <span className="truncate text-sky-100/80">
          {gs.characters[id]?.[locale]}
        </span>
      </div>
    ))}
  </div>
</div>
```
(проверить, что после удаления не осталось лишних пустых обёрток/JSX
fragments — блок находится внутри той же `GlassCard`, что и таблица
результатов, после неё; убедиться что закрывающие теги карточки
остаются корректными).
