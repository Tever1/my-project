# TASK-141: Кнопка "Добавить игрока" в меню комнаты

## Цель
Добавить в `RoomMenu` кнопку-приглашение, которая копирует ссылку для вступления в игру в буфер обмена.

## Whitelist файлов
- `src/components/lobby/Lobby.tsx` — единственный файл

## Что делать

В компоненте `RoomMenu` (около строки 2116) уже есть QR-код (`joinUrl = ${origin}/lobby/${roomCode}`).

Нужно добавить кнопку **"Добавить игрока"** прямо над или под QR-блоком.

### Поведение кнопки

1. При клике — копирует в буфер: `${origin}/join/${roomCode}` (путь `/join/`, не `/lobby/`)
2. После копирования — меняет текст кнопки на "Скопировано ✓" на 2 секунды, затем возвращает исходный
3. Показывать кнопку только если `isCurrentUserHost === true` (только хост может добавлять)

### Внешний вид

Использовать стиль существующей кнопки `RoomMenuActionButton` (или просто inline кнопку в той же стилистике — белый текст, прозрачный фон, border rgba(255,255,255,0.15), border-radius 10, padding "10px 16px").

Текст кнопки: "Пригласить игрока" (исходное состояние), "Ссылка скопирована ✓" (после клика, 2 сек).

### Где вставить

Искать в `RoomMenu` блок с QR-кодом (`<QRCode value={joinUrl}`). Вставить кнопку ПОСЛЕ этого блока, но ДО секции со списком игроков.

## Acceptance
- Кнопка видна в меню комнаты (только для хоста)
- Клик копирует URL вида `http://192.168.0.91:3000/join/ROOMCODE` в буфер
- Текст меняется на "Ссылка скопирована ✓" на 2 секунды
- `npm run lint` без новых ошибок

## Не трогать
- Логику QR-кода, `localIp`, `joinUrl`
- Компоненты вне `Lobby.tsx`
- `CLAUDE.md`, `AGENTS.md`, `codex-tasks/`, `.codex/`
