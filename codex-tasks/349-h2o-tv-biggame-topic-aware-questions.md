# TASK-349: TV «100 к 1» — Большая игра использует не ту тему вопросов

## Whitelist файлов
- `src/app/tv/[roomId]/[gameType]/page.tsx`

## Баг

На TV-экране (игровое поле) в фазе «Большая игра» блок вопросов всегда
рендерится из хардкод-импорта `H2O_BIG_Q` (общая тема, `BIG_Q_GENERAL`),
независимо от реальной темы, выбранной в комнате (`h.topicId`).

Для сравнения — в основной игре (раунды 1-4) TV уже корректно резолвит
тему:

```ts
const activeRounds = H2O_TOPICS.find(t => t.id === h.topicId)?.rounds ?? H2O_ROUNDS;
```

Но для «Большой игры» (`h.phase === 'bigGame'`, ~строка 1353) используется
жёстко `H2O_BIG_Q.map(...)`, а не тема-зависимый список.

**Следствие:** если игра шла не по общей теме (например «Кино» или
«Космос»), мобильный хост считает очки против правильного
тема-специфичного списка вопросов (`topic.bigQ`), а TV параллельно рендерит
ОБЩИЕ вопросы и ищет очки через `qq.answers.find(a => a.t === matched)` в
общем списке — тексты не совпадают, `find` не находит совпадение, `?.p`
уходит в `undefined`, срабатывает фолбэк `|| 0`. На экране это выглядит как
зелёная (правильная, «matched») галочка с «+0» очков вместо реальных очков.

## Фикс

В блоке TV-рендера `100 к 1` (строка ~1152, где уже есть `activeRounds`)
добавить аналогичный резолв для Big Game:

```ts
const activeBigQ = H2O_TOPICS.find(t => t.id === h.topicId)?.bigQ ?? H2O_BIG_Q;
```

И в блоке «Big Game phase» (строка ~1353) заменить
`H2O_BIG_Q.map((qq, i) => {` на `activeBigQ.map((qq, i) => {`.

Больше нигде `H2O_BIG_Q` в файле не используется для рендера — только в
этом одном месте (проверено через grep). Импорт `H2O_BIG_Q` можно оставить
как fallback-значение в `??` выражении (см. паттерн `activeRounds` выше) —
не удалять импорт.

## Acceptance

- `activeBigQ` резолвится тем же паттерном что и `activeRounds` (та же
  строка структуры, просто `.bigQ` вместо `.rounds`).
- Блок Big Game использует `activeBigQ` вместо `H2O_BIG_Q` для `.map(...)`.
- `npx next build --webpack` (или `npx tsc --noEmit`) проходит без новых
  ошибок в этом файле.
- Не трогать логику мобильного экрана (`src/app/game/[roomId]/hundred-to-one/page.tsx`)
  — там уже всё top-aware (`const BIG_Q = topic.bigQ;`), баг только на TV.
