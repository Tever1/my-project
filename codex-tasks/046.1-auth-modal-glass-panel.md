# TASK-046.1: AuthDropdown — frosted glass как RoomMenu

## Проблема

TASK-046 добавил радиальный градиент на контейнер-оверлей (мобайл), но сама панель
осталась тёмно-непрозрачной `rgba(18,18,28,0.92)`. Через неё не видно градиент
лобби, поэтому фон не совпадает с RoomMenu.

RoomMenu использует `rgba(255,255,255,0.08)` — прозрачное стекло, сквозь которое
виден per-game градиент лобби. Нужно то же самое для AuthDropdown.

## Файлы

**Whitelist:** только `src/components/lobby/Lobby.tsx`

## Изменения

### Функция `AuthDropdown`, `panelStyle` (~строка 1262)

Заменить **всю переменную `panelStyle`**:

С:
```ts
const panelStyle: React.CSSProperties = {
  width: isMobile ? '100%' : 320,
  maxWidth: isMobile ? 400 : undefined,
  background: 'rgba(18, 18, 28, 0.92)',
  backdropFilter: 'blur(32px)',
  WebkitBackdropFilter: 'blur(32px)',
  border: `1px solid ${accent}33`,
  borderRadius: 20,
  padding: 24,
  boxShadow: `0 24px 64px rgba(0,0,0,0.6), 0 0 0 1px ${accent}22`,
};
```

На:
```ts
const panelStyle: React.CSSProperties = {
  width: isMobile ? '100%' : 320,
  maxWidth: isMobile ? 400 : undefined,
  background: 'rgba(255,255,255,0.08)',
  backdropFilter: 'blur(24px)',
  WebkitBackdropFilter: 'blur(24px)',
  border: '1px solid rgba(255,255,255,0.12)',
  borderRadius: 20,
  padding: 24,
  boxShadow: `0 24px 64px rgba(0,0,0,0.5), 0 0 0 1px ${accent}22`,
};
```

Это точно тот же стиль, что у RoomMenu (`GlassPanel variant="floating"`):
- `rgba(255,255,255,0.08)` вместо тёмного непрозрачного — лобби-градиент просвечивает
- `blur(24px)` вместо `blur(32px)` — стандартный для floating-панелей
- `rgba(255,255,255,0.12)` border — тот же что у RoomMenu
