# TASK-015.1: Visual left-to-right keyboard order в TopBar

> **Сложность:** simple
> **Запуск:** auto by Claude

## Проблема

После TASK-015 keyboard order = `['play', 'friends', 'history', 'room']`,
где `friends` = FriendsOnlinePill (right side), потому что NavButton
«Друзья» лишился `topbarId`. Стрелка → теперь прыгает: Играть (left) →
FriendsOnlinePill (right!) → История (left) → RoomButton (right).
Визуально ломается left-to-right ход.

## Цель

Восстановить natural visual order с обеими «friends» элементами как
отдельными точками:

`play (Играть) → friends-nav (Друзья) → history (История) → friends-online (Друзей онлайн pill) → room (Создать комнату)`

## Файлы

- `src/app/lobby-preview/page.tsx` — только.

## Шаги

1. **NavButton «Друзья»** — добавить `topbarId="friends-nav"`.
2. **FriendsOnlinePill** — поменять `topbarId="friends"` →
   `topbarId="friends-online"`.
3. **Order array** в keydown handler:
   ```ts
   const order = ["play", "friends-nav", "history", "friends-online", "room"];
   ```
