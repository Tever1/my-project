# TASK-370: TV «100 к 1» Большая игра — не растягивать карточку вопроса, когда виден только один

## Контекст

TASK-368 добавил условие в `src/app/tv/[roomId]/[gameType]/page.tsx`
(строка ~1618): на `bgPhase === 1 || bgPhase === 3` в списке вопросов
(строка ~1616-1638) рендерится только текущий вопрос (`i === h.bgCurQ`),
остальные — `return null`.

Проблема: карточка каждого вопроса (строка ~1630) имеет класс `flex-1`:

```tsx
<div key={i} className={`flex flex-1 items-center gap-5 rounded-[var(--radius-xl)] border px-[26px] py-4 backdrop-blur-[20px] ${current ? 'border-amber-300/50 bg-amber-500/[.08]' : 'border-white/10 bg-white/[.06]'}`}>
```

Родитель — `<div className="flex min-h-0 flex-col gap-3">`. Когда рендерится
6 карточек, `flex-1` распределяет высоту контейнера поровну между ними —
каждая карточка получается компактной. Но когда (на `bgPhase === 1/3`)
рендерится только ОДНА карточка, `flex-1` заставляет её растянуться на всю
доступную высоту контейнера — получается неестественно большая, некрасивая
карточка на весь экран.

## Что сделать

Карточка вопроса должна сохранять тот же размер, что и раньше (как одна из
шести), а не растягиваться на всю высоту, когда она единственная. Убрать
`flex-1` с самой карточки (заменить на естественную высоту по контенту) и
центрировать список по вертикали, когда виден только один вопрос.

Вариант реализации — обернуть список в условную обёртку:

```tsx
<div className={`flex min-h-0 flex-col gap-3 ${(h.bgPhase === 1 || h.bgPhase === 3) ? 'justify-center' : ''}`}>
  {activeBigQ.map((qq, i) => {
    if ((h.bgPhase === 1 || h.bgPhase === 3) && i !== h.bgCurQ) return null;
    ...
    return (
      <div key={i} className={`flex items-center gap-5 rounded-[var(--radius-xl)] border px-[26px] py-4 backdrop-blur-[20px] ${(h.bgPhase === 1 || h.bgPhase === 3) ? '' : 'flex-1'} ${current ? 'border-amber-300/50 bg-amber-500/[.08]' : 'border-white/10 bg-white/[.06]'}`}>
        ...
      </div>
    );
  })}
</div>
```

То есть:
- на `bgPhase === 2 || bgPhase === 4` (проверка, показаны все 6/5 карточек) —
  поведение НЕ меняется, `flex-1` остаётся, карточки делят высоту поровну
  как раньше.
- на `bgPhase === 1 || bgPhase === 3` (виден один вопрос) — у карточки убрать
  `flex-1` (она принимает высоту по контенту — `py-4` паддинг, как одна
  строка из шести), а родительский flex-контейнер получает `justify-center`,
  чтобы единственная карточка была вертикально отцентрирована в отведённой
  области, а не растянута.

Ничего внутри самой карточки (иконка номера, текст вопроса, чипы ответов) не
менять — только классы `flex-1`/`justify-center`, описанные выше.
