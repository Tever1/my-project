# TASK-233: Spy TV — убрать дублирование имени игрока

## Контекст

На TV-экране Шпиона имя игрока показывается дважды (аватар-кружок с инициалом
+ текстовое имя). Пользователь хочет в каждом месте оставить только ОДНО
представление. Все правки — в одном файле, только в блоке `if (gameType === 'spy')`.

## Whitelist (трогать ТОЛЬКО это)

- `src/app/tv/[roomId]/[gameType]/page.tsx`

ЗАПРЕЩЕНО: всё остальное. Не трогать другие игры в этом файле.
**Минимальный diff: не переформатировать и не переупорядочивать нетронутые строки.**

## Правки

### #1 — Playing «Сейчас отвечает»: убрать кружок, оставить простое имя

Было (≈ строки 1284–1289):
```tsx
                  <div className="flex items-center gap-4">
                    <div className="w-16 h-16 rounded-full bg-teal-500/20 border border-teal-400/30 flex items-center justify-center text-2xl font-bold">
                      {activePlayerName[0]}
                    </div>
                    <span className="text-5xl font-black">{activePlayerName}</span>
                  </div>
```
Стало:
```tsx
                  <span className="text-5xl font-black">{activePlayerName}</span>
```

### #2 — Порядок хода: оставить только кружок с инициалом (убрать текст-имя под ним)

Было (≈ строка 1411):
```tsx
                      <span className="text-xs">{spyGetName(id)}</span>
```
Стало: удалить эту строку целиком. Кружок-аватар выше и бейдж «говорит/рисует»
ниже — ОСТАВИТЬ как есть.

### #3 — Голосование «Кто шпион?»: убрать кружок, оставить простое имя

Было (≈ строки 1325–1327):
```tsx
                        <div className="w-12 h-12 rounded-full bg-white/10 flex items-center justify-center text-lg font-bold">
                          {p.nickname[0]}
                        </div>
```
Стало: удалить этот блок-кружок целиком. Строку
`<span className="font-semibold">{p.nickname}</span>` ниже — ОСТАВИТЬ.

### #4 — Итоги раунда «Шпионом был(а)»: оставить имя в кружочке (убрать большое имя-текст)

Было (≈ строка 1366):
```tsx
                  <p className="text-3xl font-black">{spyName}</p>
```
Стало: удалить эту строку целиком. Кружок-аватар с инициалом и иконкой-маской
выше (`<div className="relative">…`) — ОСТАВИТЬ.
