# TASK-316: Alias mobile "Игра окончена" — имя команды налезает на счёт, убрать медаль

## Контекст

На экране `finished` (итоги игры) каждая строка команды — это `flex justify-between`
с именем слева и счётом справа. У длинного имени команды (тестовое
`"5345234523"`, 10 символов — максимум по TASK-313) нет ни `truncate`, ни
`flex-shrink`/`min-width: 0` — оно физически наезжает на счёт, последняя цифра
имени и цифры счёта визуально сливаются в одну строку (см. скриншот юзера).
Юзер просит: (1) уменьшить шрифт имени команды так, чтобы оно красиво влезало
в строку рядом со счётом, не наезжая; (2) убрать иконку медали слева от имени
команды — на этом экране она не нужна.

## Файл (whitelist — только один)

- `src/app/game/[roomId]/alias/page.tsx`

Конкретно блок "FINISHED", строки ~1227–1242:

```tsx
{gameState.teams
  .sort((a, b) => b.score - a.score)
  .map((team, i) => (

        i === 0 ? 'bg-amber-500/10 outline outline-1 outline-amber-400' : 'bg-white/5'
      }`}
    >
      <span className="text-lg font-bold text-white">
        <AliasIcon name="medal" className="mr-1 inline-block h-[1em] w-[1em] align-[-0.15em]" />{' '}
        {team.name}
      </span>
      <span className="text-2xl font-bold text-amber-400">{team.score}</span>
    </div>
  ))}
```

## Что сделать

1. **Убрать иконку медали** — удалить `<AliasIcon name="medal" .../>` и
   связанный `{' '}` перед именем команды.
2. **Починить переполнение имени:**
   - Имя команды должно сжиматься, а не наезжать на счёт: оберни/переделай
     так, чтобы у span/контейнера с именем было `min-w-0` + `truncate` (или
     `overflow-hidden text-ellipsis whitespace-nowrap`), и он не выталкивал
     счёт за пределы строки. Контейнер-строка (`flex items-center
     justify-between`) — добавь `gap-3` между именем и счётом, если его нет.
   - Уменьши шрифт имени команды так, чтобы 10-символьное имя (максимум по
     TASK-313) комфортно помещалось рядом со счётом без truncate в норме —
     например с `text-lg` на `text-base` или `text-sm` (на усмотрение, под
     ширину карточки `max-w-md` минус padding минус ширина счёта). Счёт
     (`text-2xl`) не трогать.
   - Если имя всё равно слишком длинное даже при уменьшенном шрифте — должен
     сработать `truncate`, а не наезд на счёт.
3. Не трогать остальную структуру/логику (`sort`, ключи, классы строки-обёртки
   кроме добавления `gap`/`min-w-0`/`truncate`), не трогать другие фазы.
