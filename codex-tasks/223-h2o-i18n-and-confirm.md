## Контекст

`hundred-to-one/page.tsx` не импортирует `useTranslation`. Конвенция (см.
`mafia/page.tsx`, `who-am-i/page.tsx`): хелпер
`const l = useCallback((ru: string, en: string) => (locale === 'ru' ? ru : en), [locale]);`
и оборачивание КАЖДОЙ видимой строки в `l('ru', 'en')` — включая JSX-текст,
плейсхолдеры инпутов, и интерполяции (template literals → собирать через `l`).

`GameLayout` сам подтверждает завершение игры — `endGame` должен завершать сразу.

## Шаги реализации

1. `import { useTranslation } from '@/lib/i18n';`, `const { locale } =
   useTranslation();`, добавить хелпер `l`.
2. Обернуть ВСЕ видимые русские строки в `l(ru, en)`:
   - JSX-текстовые узлы;
   - строковые литералы, попадающие в UI (заголовки, подписи, кнопки, статусы);
   - `placeholder=` у инпутов;
   - template-literals с русским текстом — переписать через `l(...)` +
     интерполяция (напр. `` `Начинает ${name}` `` → `` `${l('Начинает','Starts')} ${name}` ``).
3. `endGame` (строка ~408): убрать `confirm()`, оставить тело:
   ```ts
   emit('game:end', { code: roomId });
   router.push(user ? `/lobby/${roomId}` : `/join/${roomId}`);
   ```
   (`router`/`user` уже из TASK-221.)
4. `title="100 к 1"` → `title={l('100 к 1', '100 to 1')}`.

### Глоссарий (для консистентности перевода)

- Команда → Team · Ведущий → Host · Капитан → Captain
- Раунд → Round · Банк → Bank · Страйк → Strike · Очки → Points
- ПРОСТАЯ → SIMPLE · ДВОЙНАЯ → DOUBLE · ТРОЙНАЯ → TRIPLE · НАОБОРОТ → REVERSE
- Большая игра → Big Game · Игрок 1/2 → Player 1/2
- Ждём… → Waiting… · Никому → Nobody · Себя → Self
- НАЧАТЬ ИГРУ → Start Game · Далее → Next · Итоги → Results
- Продолжить/ПРОДОЛЖИТЬ → Continue · Старт/СТАРТ → Start
- Завершить игру → End game · сменить → change · выбран → selected
- «Угадай слово»/режимы и т.п. переводить по смыслу.

### Особый случай — дефолтные имена команд

Строки-данные `'Команда 1'` / `'Команда 2'` (строки 69, 180), которые пишутся
в состояние (`t1n`/`t2n`) как ДЕФОЛТ — оставить русскими **как данные** (они
редактируются капитанами и хранятся в общем состоянии; локализовать их по месту
нельзя без рассинхрона). НО там где они показываются как **подпись-плейсхолдер**
для пустого значения (напр. `placeholder` или fallback-лейбл выбора команды на
экране ролей, строки ~628-629, 676) — обернуть в `l('Команда 1','Team 1')` /
`l('Команда 2','Team 2')`. Если сомнение — оставить как данные и отметить в отчёте.
