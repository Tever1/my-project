# TASK-203: Управление игроками хостом на телефоне (/join)

> **Метаданные**
> - **Дата создания:** 2026-06-02
> - **Сложность:** complex
> - **Запуск:** auto by Claude
> - **Зависит от тасков:** 202

---

## Цель

1. На телефоне ХОСТА в списке игроков (`/join/[code]`): тап по игроку открывает
   выпадающее меню с опциями **«Передать хост»** и **«Удалить игрока»**.
2. Показывать ошибку «В комнате нет игроков», когда хост жмёт «НАЧАТЬ ИГРУ» при
   0 игроках (эвент `game:error` от сервера, TASK-202).

---

## Контекст

Багрепорт 2026-06-02. Телефон-хост сидит на `/join/[code]` (PlayerJoinView), а не
в Lobby — там и должны быть кнопки управления игроками. Сейчас список игроков
(`src/app/join/[code]/page.tsx:280`) — просто чипы с ником и бейджем «ведущий»,
без действий.

Хост определяется как `roomState.gameHostPlayerId === playerId` (та же логика, что
`canStartGame`). Сервер (TASK-202) уже проверяет права на `room:kick`/
`room:transfer-host` и шлёт `game:error` при старте с 0 игроками.

Страница `/join` монолингвальна (русский — «ведущий», «Ожидание ведущего…»);
следовать этому: русские строки.

---

## Файлы к изменению (whitelist)

- `src/app/join/[code]/page.tsx`:
  1. **Тап по игроку → меню действий.** Если текущий телефон — хост
     (`gameHostPlayerId === playerId`) И строка не своя (`player.id !== playerId`):
     сделать чип игрока кликабельным; по тапу открыть выпадающее меню (state
     `selectedPlayerId`) с кнопками:
     - «Передать хост» → `emit('room:transfer-host', { code, newHostId: player.id })`
     - «Удалить игрока» → `emit('room:kick', { code, playerId: player.id })`
     Меню закрывается по выбору и по тапу вне (как в Lobby RoomMenu — паттерн
     `selectedPlayerId` + pointerdown-листенер можно скопировать идейно, не
     импортируя).
  2. **Ошибка 0 игроков.** Подписаться на `on('game:error', ({ messageRu }) => ...)`
     и показать сообщение (inline-текст или простой toast/alert в стиле страницы).
     Не блокировать UI — просто сообщить.
  3. Не-хост игроки видят список без действий (как сейчас).

## Шаги реализации

1. Добавить state `selectedPlayerId` + закрытие по внешнему тапу.
2. Сделать чип игрока кликабельным только для хоста и только для чужих строк.
3. Выпадающее меню с двумя действиями → соответствующие `emit`.
4. `on('game:error')` → показать «В комнате нет игроков».

> Если выяснится, что нужен серверный довесок (например, `game:error` не доходит) —
> остановиться, описать в отчёте, не править сервер в этом таске.
