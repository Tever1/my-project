# TASK-253 — Крокодил: интеграция дизайна Claude Design (Вариант 2), КРАСНАЯ тема

## Контекст

Claude Design отдал два HTML-мокапа «Вариант 2» для Крокодила:
- **TV / игровое поле** — «центр-герой»: круговой таймер слева + кто показывает
  (аватар + имя) справа, шапка с счётчиками «Угадано / Пропущено», снизу таблица
  очков карточками.
- **Телефон / пульт** — «флэш-карта»: верхний прогресс-бар + большая карточка слова
  (видна только объясняющему), чипы угадывающих, кнопки «Пропустить»/«Угадали»,
  «Передать ход».

Мокапы построены на ЗЕЛЁНОМ акценте (#30d158). **РЕШЕНИЕ ПОЛЬЗОВАТЕЛЯ: Крокодил
остаётся КРАСНЫМ** (палитра проекта #ef4444, фон `.bg-gradient-crocodile` уже
красный из TASK-252). Поэтому ВСЕ зелёные брендовые акценты дизайна
перекрашиваются в красную гамму. Семантические цвета действий сохраняются:
«Угадали» = зелёная success, «Пропустить» = нейтральная (на красном фоне красная
кнопка нечитаема).

Это чисто **визуальная** интеграция: игровая логика, socket-события, схема очков
НЕ меняются. Перерабатываем только фазу `explaining` на обоих экранах. Фазы
`waiting` и `finished` оставить как есть (они работают, фон уже красный).

## Жёсткие правила (immutable, НЕ нарушать)

1. **Схема очков НЕ меняется** (CLAUDE.md #4): очки получает объясняющий по кнопке
   «Угадали» (+1). «Пропустить» очков не даёт, инкрементит `wordsSkipped`.
   Не-объясняющий видит «Угадывайте вслух!». Никакого пер-игрокового ввода.
   → Чипы угадывающих в дизайне («нажми кто угадал») рендерить как
   **ИНФОРМАЦИОННЫЕ** (просто список «Угадывают»), БЕЗ кликов/начисления.
2. **Категория слова — НЕ показывать.** В `CROCODILE_WORDS` (`src/lib/game-data.ts`)
   нет поля категории. Пилюлю «Профессии/Предметы/Категория» из дизайна ОПУСТИТЬ.
   Не выдумывать данные, не трогать game-data.
3. **Двуязычность** (CLAUDE.md #1): все видимые строки — пара ru/en через `locale`.
4. **Никаких новых socket-событий, фаз, удалений механик.** Кнопки и обработчики —
   те же, что сейчас (`croc:guessed`, `croc:skip`, `croc:next-player`, `croc:state`,
   `croc:tick`). «Передать ход» на телефоне объясняющего → переиспользует
   существующий `croc:next-player` (см. ниже).
5. **Фон только через GameSurface / GameLayout** (CLAUDE.md #7). Не добавлять
   руками `<img -z-10>` + isolate.

## ЧАСТЬ A — Телефон (мобильный экран), фаза `explaining`

Файл: `src/app/game/[roomId]/crocodile/page.tsx`, блок
`{gameState?.phase === 'explaining' && (...)}` (строки ~428–588).

Эталон макета: `Крокодил - Телефон · Вариант 2.html` (флэш-карта). Структура
сверху вниз:

### A1. Верхний статус-бар (вместо текущего таймер-числа + бар)
- Строка из двух элементов: слева моно-капс лейбл хода
  `ХОД {currentRound} / {totalRounds}` (en: `TURN {currentRound} / {totalRounds}`),
  справа моно-таймер в формате `m:ss` (отформатировать `gameState.timeLeft`,
  напр. 42 → `0:42`).
- Под ними тонкий прогресс-бар (h≈6px, rounded): ширина =
  `(timeLeft / TURN_DURATION) * 100%`, заливка `linear-gradient(90deg, ${RED}, ${RED2})`
  + лёгкое свечение `box-shadow: 0 0 12px ${RED}`. При `timeLeft<=10` —
  бар становится ярче/пульсирует (как сейчас, можно оставить red-pulse).

### A2. Карточка слова — ТОЛЬКО для объясняющего (`isExplainer`)
Большая скруглённая карточка (radius ~36, flex:1), заливка
`linear-gradient(165deg, ${RED} 0%, ${RED_DARK} 100%)`, сверху блик
`radial-gradient(110% 70% at 50% -5%, rgba(255,255,255,.35), transparent 55%)`,
тень `0 24px 60px -18px ${RED}cc`. Внутри:
- Верхняя строка: слева — НИЧЕГО (категорию опускаем, п.2); справа — эмодзи 🐊 (≈34px).
  (Т.к. категории нет — можно слева оставить пусто или мелкий лейбл «Слово»/`Word`
  капсом полупрозрачным белым. На усмотрение, но БЕЗ выдуманной категории.)
- Центр: слово огромным шрифтом (`font-black`, ~54px, `letter-spacing:-1.5`,
  `line-height:.95`, центр, БЕЛЫЙ текст с тенью). Источник:
  `locale==='ru' ? currentWord.ru : currentWord.en`.
- Низ карточки: мелкий капс-лейбл «Угадывают» (en: `Guessing`) полупрозрачным
  белым, под ним ряд чипов угадывающих (все игроки кроме объясняющего):
  чип = pill `rgba(0,0,0,.18)` с `PlayerAvatar size sm/26px` + имя.
  **Информационно, без onClick.** Игроки: `players.filter(p => p.id !== explainerId)`,
  показать первые 4–5, если влезает.

### A3. Карточка для НЕ-объясняющего (`!isExplainer`)
Оставить существующую логику «Угадывайте вслух! 🗣️» + «{explainer} объясняет
слово», но завернуть в карточку в том же красном стиле (можно проще: GlassCard
или красная карточка без слова). Функциональность не менять.

### A4. Кнопки действий — ТОЛЬКО для объясняющего (`isExplainer`)
Сетка 2 колонки, высота кнопок ~76px, radius ~24:
- **Пропустить** (левая): нейтральная/секондари (НЕ красная — фон уже красный),
  иконка ✕ + подпись. onClick = текущая логика
  (`isGameHost ? handleSkip() : emitAction('croc:skip')`).
- **Угадали** (правая): зелёная success-заливка
  `linear-gradient(180deg, #4bed7a, ${SUCCESS})`, тёмно-зелёный текст `#05210f`,
  иконка ✓ + подпись. onClick = текущая логика
  (`isGameHost ? handleGuessed() : emitAction('croc:guessed')`).

### A5. Кнопка «Передать ход» (full-width, secondary, под кнопками)
Показывать объясняющему. onClick:
```
if (isGameHost) { clearInterval(timerRef.current); advanceToNextExplainer(gameState); }
else { emitAction('croc:next-player'); }
```
(Хост уже слушает `croc:next-player` и вызывает advanceToNextExplainer.)
en-подпись: `Pass turn`, ru: `Передать ход`.

### A6. Существующий хостовый блок «Следующий игрок →» (host && !isExplainer)
Оставить как есть. Нижнюю карточку «Счёт» (scoreboard summary) можно оставить
как есть (она информативна) — НЕ обязательно перерисовывать, но привести отступы
к новому макету по возможности.

## ЧАСТЬ B — TV / игровое поле, фаза `explaining`

### B1. Шапка (уже есть, доработать счётчики)
Слева: 🐊 + «Крокодил/Crocodile» + бейдж `Раунд {currentRound} / {totalRounds}`
(красный бейдж). Справа: ДВА счётчика-карточки (как `CounterStat` в мокапе):
- «Угадано / Guessed» = `crocState.wordsGuessed`, цвет RED (#ef4444), иконка ✓.
- «Пропущено / Skipped» = `crocState.wordsSkipped`, цвет `#ff9f0a` (оранж), иконка ›.
Карточка счётчика: иконка в цветном квадрате `${color}22` + крупное число
(`font-black` ~44px цвет color) + капс-лейбл снизу.

### B2. Центр — герой (главное изменение)
Горизонтальный flex, центрирован, gap ~60px:
- **Слева — круговой таймер** (TimerRing): SVG-кольцо ~280px. Переиспользуй ПАТТЕРН
  уже существующего кольца в этом же файле (Spy, строки ~1238/1276:
  `r`, `2πr`, `strokeDasharray`/`strokeDashoffset`, `rotate(-90deg)`,
  `transition: stroke-dashoffset 1s linear`). Кольцо: фон-трек
  `rgba(255,255,255,.08)` strokeWidth ~14; прогресс цветом RED (#ef4444),
  `drop-shadow(0 0 12px #ef444488)`. `offset = CIRC * (1 - timeLeft/60)`.
  В центре — число `timeLeft` крупным моно. При `timeLeft<=10` — цвет ярче +
  `animate-pulse` (как сейчас). max = 60.
- **Справа — кто показывает:** колонка, align-start:
  - капс-лейбл «Показывает слово» (en: `Showing the word`) полупрозрачным.
  - строка: `PlayerAvatar` ~88px с красным ring (#ef4444) + имя объясняющего
    огромным (`font-black` ~56px, `letter-spacing:-1.5`).
  - (Категорию НЕ показывать, п.2.)
- **Слово на TV НЕ показывать** (его угадывают — это правильно, как в мокапе).

### B3. Низ — таблица очков карточками
Вместо текущей grid-2 сетки бейджей — карточки игроков как в мокапе. Контейнер —
полупрозрачная панель (`rgba(255,255,255,.05)`, border `0.5px rgba(255,255,255,.1)`,
radius ~24, тень) с заголовком (🏆 «Таблица очков / Scoreboard»). Внутри
`grid` по числу игроков (`repeat(N, 1fr)`, N = sortedScores.length, разумно до 6–8):
каждая карточка — колонка:
- ранг `#1..#N` моно; для топ-3 цвета медалей `['#ffd60a','#c7cdd6','#cd8e54']`,
  остальные — tertiary.
- `PlayerAvatar` ~48px, для активного (id === explainerId) — красный ring.
- имя (`font-bold` ~15px).
- очки крупным моно (`font-black` ~26px, белый).
- активная карточка: фон `linear-gradient(180deg, #ef44442e, rgba(255,255,255,.04))`
  + border `1px #ef444466`; неактивные — `rgba(255,255,255,.04)` + тонкий бордер.

Данные: `sortedScores` (уже есть, отсортирован по score desc), `crocState.explainerId`.

### B4. Вписать в экран
Весь блок не должен вылезать за высоту (`h-screen`, overflow-hidden). Сохранить
`flex-shrink-0` где нужно, центр-герой во `flex-1 min-h-0`, таблица снизу
фикс-высотой по контенту. Шрифты крупные (TV смотрят с 3м), но без переполнения.
