# TASK-350: «100 к 1» — «Сброс раунда» не откатывает очки за фонд раундов 1-3

## Whitelist файлов
- `src/app/game/[roomId]/hundred-to-one/page.tsx`

## Баг

Если в раунде 1-3 («ПРОСТАЯ/ДВОЙНАЯ/ТРОЙНАЯ ИГРА») открыть все 6 ответов
(или раунд завершился через strike-переход `switched` → 3 страйка активной
команды), весь `roundFund[curQ]` разово начисляется команде-победителю
(`roundPhase[curQ] = 'won'`, `roundWonBy[curQ] = <team>`, см. `openAns`
строки 299-313 и `addStrike` строки 371-378). Если после этого хост жмёт
«Сброс раунда» (`resetRound`, строка 394), очки не откатываются — команда
остаётся с приплюсованными очками, хотя раунд визуально сброшен.

**Причина:** `resetRound` откатывает очки только через цикл

```ts
s.qState[ri].forEach((a, idx) => {
  const pts = getDisplayPts(ri, idx, q.answers[idx].p);
  if (a.to === 1) newT1s -= pts;
  else if (a.to === 2) newT2s -= pts;
});
```

Это верно для раунда 4 («наоборот»), где каждый ответ явно назначается
команде через `a.to = 1/2` (см. `assignPts`, строка 344-353). Но в раундах
1-3 `a.to` для ответа никогда не равен `1` или `2` — там используются
только `-1` (ответ открыт, ждёт исхода раунда) и `0`. Начисление очков
идёт лямпом (`newT1s/newT2s += newFund[s.curQ]`) при переходе фазы раунда
в `'won'`, а `resetRound` этот путь не учитывает вовсе.

## Фикс

В `resetRound` (строка 394, `src/app/game/[roomId]/hundred-to-one/page.tsx`)
после существующего цикла по `a.to` добавить откат фонда для раундов 1-3,
если раунд уже был выигран:

```ts
// Rounds 1-3: score awarded as a lump fund credit when round finished ('won')
if (ri <= 2 && s.roundPhase[ri] === 'won') {
  const winTeam = s.roundWonBy[ri];
  if (winTeam === 1) newT1s -= s.roundFund[ri];
  else if (winTeam === 2) newT2s -= s.roundFund[ri];
}
```

Вставить это сразу после блока `s.qState[ri].forEach(...)` (до
`const newQState = ...`), используя уже существующие переменные
`newT1s`/`newT2s` из внешней области видимости функции.

## Acceptance

- Открыть все 6 ответов в раунде 1 (или довести раунд до switched→3
  страйка → won), очки команде начислились → нажать «Сброс раунда» →
  очки команды должны вернуться к значению ДО раунда (а не остаться
  приплюсованными).
- Раунд 4 («наоборот») не трогать — там логика через `a.to` уже
  корректна, менять её не нужно.
- Обычный сброс раунда без завершения (`roundPhase !== 'won'`) — поведение
  не меняется (условие `s.roundPhase[ri] === 'won'` не сработает).
- `npx tsc --noEmit` и `npm run lint` проходят.
