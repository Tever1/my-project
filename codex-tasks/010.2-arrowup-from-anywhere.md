# TASK-010.2: ArrowUp работает из любого места (не только когда фокус на тайле)

> **Сложность:** simple
> **Запуск:** auto by Claude
> **Зависит от:** TASK-010, TASK-010.1

---

## Проблема

Сейчас `ArrowUp` фокусирует «Начать партию» только если `focused?.dataset?.gameId !== undefined`,
т.е. фокус строго на тайле. Но после клика мышью по тайлу фокус часто уходит на `body`
(например при `motion.button` с framer-motion), и `dataset.gameId` будет `undefined` — кнопка не сработает.

## Цель

`ArrowUp` фокусирует «Начать партию» если:
- фокус в tile-strip (`dataset.gameId` есть), **ИЛИ**
- фокуса нет на интерактивном элементе (focused это `<body>`, `<html>` или `null`).

`ArrowDown` уже корректен (работает только когда фокус на CTA).

## Файлы к изменению

- `src/app/lobby-preview/page.tsx` — только.

## Шаги

В обработчике `keydown`, в ветке `e.key === "ArrowUp"`:

```ts
} else if (e.key === "ArrowUp") {
  const focusedTag = focused?.tagName;
  const inTileStrip = focused?.dataset?.gameId !== undefined;
  const isOnBody = !focused || focusedTag === 'BODY' || focusedTag === 'HTML';
  // ИЛИ можно: focused это не button/input/a/textarea/[contenteditable]
  if (inTileStrip || isOnBody) {
    e.preventDefault();
    startGameButtonRef.current?.focus();
  }
}
```

Логика «не на интерактивном» — отбрасывает случаи когда юзер в input или
другой button (не хотим перехватить ArrowUp у чужих контролов).
