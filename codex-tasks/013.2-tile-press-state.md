# TASK-013.2: Press effect через явное state (mouse + Enter)

> **Сложность:** simple
> **Запуск:** auto by Claude

## Проблемы

1. **Mouse-клик первый раз на тайле не показывает press** для тайлов 0-4
   (mafia/quiz/crocodile/spy/alias). Со второго клика работает. Тайлы 5-6
   (who-am-i, hundred-to-one) работают сразу. Причина — race между hover
   и whileTap анимациями.
2. **Enter на тайле НЕ показывает press** вообще. Причина: framer-motion
   `whileTap` слушает только pointer/touch events, не keyboard.

## Решение

Заменить `whileTap` на явный React state `pressed: boolean`:
- mouse pointerdown → setPressed(true), pointerup/leave → setPressed(false)
- keyDown Enter → setPressed(true), затем через 150ms setPressed(false)
- В `tileAnimate` если pressed → scale 0.92, y: -2 (поверх hover/active)

Это даст pressed effect одинаковый для mouse и keyboard, без race conditions.

## Файлы

- `src/app/lobby-preview/page.tsx` — только `function Tile`.

## Шаги

В `function Tile`:

1. Добавить state:
   ```ts
   const [pressed, setPressed] = useState(false);
   ```

2. Изменить `tileAnimate`:
   ```ts
   const tileAnimate = pressed
     ? { y: -2, scale: 0.92 }
     : isActive
       ? { y: -3, scale: 1.02 }
       : hovered
         ? { y: -5, scale: 1.04 }
         : { y: 0, scale: 1 };
   ```

3. Убрать `whileTap` (полностью).

4. Добавить обработчики на `motion.button`:
   ```ts
   onPointerDown={() => setPressed(true)}
   onPointerUp={() => setPressed(false)}
   onPointerLeave={() => setPressed(false)}
   onPointerCancel={() => setPressed(false)}
   onKeyDown={(e) => {
     if (e.key === "Enter" || e.key === " ") {
       setPressed(true);
     }
   }}
   onKeyUp={(e) => {
     if (e.key === "Enter" || e.key === " ") {
       // Hold press briefly so it's visible (Enter key release is instant)
       setTimeout(() => setPressed(false), 120);
     }
   }}
   ```

5. Использовать snappy spring для tileAnimate transitions, чтобы press
   был быстрым:
   ```ts
   transition={pressed
     ? { type: "spring", stiffness: 700, damping: 22 }
     : spring.soft
   }
   ```

6. **Важно:** keyDown с Enter — preventDefault НЕ нужен здесь (родительский
   handler уже делает фокус). Просто визуальный feedback.
