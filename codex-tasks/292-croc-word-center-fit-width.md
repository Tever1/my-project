# TASK-292 — Крокодил (мобильный): слово по центру красной карточки + подгон по ширине

## Контекст
В мобильном Крокодиле карточка слова у объясняющего (`phase === 'explaining'
&& isExplainer`, файл `src/app/game/[roomId]/crocodile/page.tsx`, около стр.
546–590) показывает слово (`FitText`) у верхнего края, а не по центру, и короткие
слова («Пианино») не дорастают до ширины поля.

Нужно:
1. Слово — строго по центру красной карточки (вертикально и горизонтально).
2. Слово подгоняется по МАКСИМАЛЬНОЙ ширине поля в зависимости от длины:
   короткие — крупнее (до ширины), длинные — ужимаются.

## Что сделать
В блоке карточки объясняющего (`gameState.phase === 'explaining' && isExplainer
&& currentWord`):

1. Обёртка слова (сейчас):
   `<div className="flex-1 min-h-0 py-8">`
   заменить на:
   `<div className="flex flex-1 min-h-0 items-center justify-center py-8">`
   (делает обёртку flex-контейнером, который центрирует FitText — не полагаемся
   на процентную высоту `h-full`).

2. У `<FitText ... max={68} min={22} ... />` поднять потолок размера:
   `max={68}` → `max={128}` (min оставить `22`).
   Это позволит коротким словам вырасти до ширины карточки, а длинным —
   автоматически ужаться (FitText уже масштабирует вниз по ширине и высоте).

Больше ничего в карточке не менять (header «Слово»/иконка, блок «Угадывают»,
градиент, тени — как есть). Карточку НЕ-объясняющего и `ready`-карточку не трогать.
