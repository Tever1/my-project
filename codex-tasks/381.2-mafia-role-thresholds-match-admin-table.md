## Цель

Исправить `assignRoles()` в `src/app/game/[roomId]/mafia/page.tsx` так, чтобы
количество ролей по числу игроков **точно** совпадало с таблицей
`roleTable` в `src/app/api/admin/game-data/route.ts` (справочная таблица на
`/admin` → Games → Мафия). Сейчас есть 2 расхождения:

1. Шериф/детектив появляется в коде с 5 игроков (`hasDetective = count >= 5`),
   а по таблице — с 4 (`sheriff: 1` уже в строке `players: 4`).
2. Доктор появляется в коде с 6 игроков (`hasDoctor = count >= 6`), а по
   таблице — с 7 (`doctor: 1` только со строки `players: 7`, в строке
   `players: 6` — `doctor: 0`).
3. Число мафии в коде — фиксированно 1 или 2 (`count >= 6 ? 2 : 1`), а по
   таблице масштабируется дальше: 1 при 4-5, 2 при 6-11, 3 при 12-14, 4 при
   15-16.
