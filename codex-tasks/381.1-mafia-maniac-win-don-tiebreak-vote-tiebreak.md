# TASK-381.1: Победа Маньяка, голос Дона только при разногласии, протокол ничьей на голосовании

> **Метаданные**
> - **Дата создания:** 2026-07-27
> - **Сложность:** complex
> - **Запуск:** auto by Claude (по прямой просьбе пользователя)
> - **Ожидаемое время Codex:** ~40-60 минут
> - **Зависит от тасков:** TASK-381

## Цель

Три точечных исправления/доработки поверх TASK-381 (роли Дон/Маньяк/
Любовница уже реализованы в `src/app/game/[roomId]/mafia/page.tsx`):

1. Реализовать условие соло-победы Маньяка.
2. Исправить голос Дона за жертву мафии — сейчас он **всегда** перебивает
   голосование мафии, должен перебивать **только при разногласии/ничьей**.
3. Добавить протокол разрешения ничьей на дневном голосовании (казнь) —
   сейчас при ничьей просто берётся первый кандидат по сортировке, без
   какой-либо обработки ничьей.

Все три пункта согласованы с пользователем и зафиксированы в `CLAUDE.md`,
раздел "Уточнения по итогам TASK-381" (сразу после спецификации ролей, под
заголовком `## Над чем работаем сейчас`). **Прочитать целиком перед
началом.**

## Контекст

TASK-381 реализовал роли Дон/Маньяк/Любовница (см.
`codex-reports/381-mafia-extended-roles-mechanics.md`) и оставил два пункта
открытыми намеренно (запрещалось додумывать продуктовые условия). Оба
уточнены пользователем. Третий пункт (протокол ничьей на дневном
голосовании) — новое уточнение, добавляет к дневному голосованию
многораундовый механизм, которого раньше не было вообще (текущий
`handleResolveVotes` просто берёт `sorted[0][0]` без проверки на ничью).

## Файлы к изменению (whitelist)

- `src/types/game.ts` — расширить `MafiaState.data`, если нужны новые поля
  для отслеживания раунда дневного голосования (см. п.3 ниже). Обновить
  `winner` union / логику, если для Маньяка нужен отдельный тип данных
  (сейчас `winner: 'mafia' | 'citizens' | 'maniac' | null` уже есть из
  TASK-381 — только включить реальный триггер).
- `src/app/game/[roomId]/mafia/page.tsx` — вся логика:
  - `checkWin()` — добавить условие: если `alive.length === 1` и
    единственный живой — Маньяк, вернуть `'maniac'`. Работает независимо от
    существующих условий mafia/citizens (Маньяк побеждает даже если формально
    "мафия побеждена" — если он последний живой, это его победа, не мирных).
  - `handleResolveNight()` — голос Дона (`donVote`) должен использоваться
    как решающий **только** когда среди голосов рядовой мафии (без Дона)
    есть разногласие/ничья (несколько кандидатов с одинаковым числом
    голосов, либо голоса вообще разделились без явного большинства). Если
    у рядовой мафии уже есть чистое большинство — идти по нему, даже если
    Дон лично проголосовал иначе.
  - `handleResolveVotes()` — реализовать протокол ничьей по CLAUDE.md:
    1. Раунд 1 (обычное голосование, как сейчас) — если явный лидер по
       голосам, выбывает как раньше (с учётом алиби Любовницы, не менять
       эту логику).
    2. Если ничья между несколькими кандидатами — начать раунд 2:
       переголосование **только среди этих кандидатов** (сузить список
       целей для голосования до кандидатов с ничьей).
    3. Если раунд 2 снова даёт ничью между теми же (или другими)
       кандидатами — раунд 3: бинарное голосование "казнить обоих" vs
       "помиловать обоих" для всего города.
    4. Если раунд 3 тоже даёт ничью — оба кандидата оправданы, никто не
       выбывает, наступает ночь (как при обычном исходе без выбывших).
    5. При исходе "казнить обоих" в раунде 3 — оба кандидата выбывают
       (применить алиби Любовницы индивидуально к каждому, если применимо).
    - Нужен UI: мобильный экран голосования должен уметь показывать сузенный
      список кандидатов (раунд 2) и бинарный выбор (раунд 3) вместо обычного
      списка игроков. TV должен отображать текущий раунд/тип голосования
      (например: "Переголосование", "Казнить обоих или помиловать?").
    - После разрешения (выбывание или оправдание) — сбросить раунд
      голосования обратно в начальное состояние для следующего дня.
- `src/app/tv/[roomId]/[gameType]/page.tsx` — отображение текущего раунда
  голосования (если для этого нужен текст/индикатор на экране, см. выше).

### НЕ ТРОГАТЬ

- Логику ночи, кроме голоса Дона (блокировки Любовницы, доктор, шериф,
  маньяк-убийство — не менять).
- Алиби Любовницы на дневном голосовании — логика "цель Любовницы не
  выбывает" должна продолжать работать на любом из раундов голосования.
- `src/app/api/admin/game-data/route.ts`, `src/app/admin/page.tsx` —
  справочная страница, не геймплей.
- `CLAUDE.md`, `AGENTS.md` — обновляет только Claude.
- 4-ролевой геймплей (mafia/detective/doctor/citizen, <10 игроков) — не
  менять поведение, кроме как для протокола ничьей на голосовании (он
  общий для всех размеров игры, раньше отсутствовал вообще, это не
  регрессия, а новая механика для всех).
