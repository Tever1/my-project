## Цель

Исправить баг: клик по кнопке в Splash не переключает экран на Lobby.

---

## Контекст

`usePlayMode()` вызывается в **двух разных компонентах** — `Splash.tsx` и
`ModeGate.tsx`. У каждого свой `useState`. Когда Splash вызывает `setMode()`,
обновляется state только в Splash — а ModeGate (который решает рендерить
Splash или children) ничего не узнаёт.

Текущий код полагается на `window` event `storage`. Но по спецификации
`storage` event срабатывает **только в других вкладках** того же origin, а
не в той, что вызвала `setItem`. Поэтому в одной вкладке два инстанса хука
не синхронизируются.

Fix: dispatch кастомного `window` event на `setMode`/`reset`, оба инстанса
подписываются на него. Это стандартный паттерн для cross-instance state без
React Context.

## Шаги реализации

1. Добавить константу события:
   ```ts
   const PLAY_MODE_EVENT = "party-hub-play-mode-change";
   ```

2. В `useEffect` подписаться **и** на `storage` (cross-tab), **и** на
   `PLAY_MODE_EVENT` (same-tab). Оба listener'а делают одно и то же —
   перечитывают localStorage и обновляют local state:
   ```ts
   useEffect(() => {
     queueMicrotask(() => {
       setModeState(parsePlayMode(window.localStorage.getItem(PLAY_MODE_KEY)));
     });

     const sync = () => {
       setModeState(parsePlayMode(window.localStorage.getItem(PLAY_MODE_KEY)));
     };

     window.addEventListener("storage", sync);
     window.addEventListener(PLAY_MODE_EVENT, sync);
     return () => {
       window.removeEventListener("storage", sync);
       window.removeEventListener(PLAY_MODE_EVENT, sync);
     };
   }, []);
   ```

3. В `setMode` и `reset` — **убрать** прямой `setModeState(...)` и заменить
   на `window.dispatchEvent(new Event(PLAY_MODE_EVENT))`. Listener выше
   подхватит и обновит state во всех инстансах (включая тот, что вызвал setMode):
   ```ts
   const setMode = useCallback((nextMode: PlayMode) => {
     window.localStorage.setItem(PLAY_MODE_KEY, nextMode);
     window.dispatchEvent(new Event(PLAY_MODE_EVENT));
   }, []);

   const reset = useCallback(() => {
     window.localStorage.removeItem(PLAY_MODE_KEY);
     window.dispatchEvent(new Event(PLAY_MODE_EVENT));
   }, []);
   ```

4. `npm run lint` и `npx tsc --noEmit`.

## Ограничения и подводные камни

- `new Event(name)` — стандартный браузерный API, IE не поддерживается, но
  Next.js 16 + наш target = современные браузеры. OK.
- Listener должен работать и на самом инстансе, который dispatch'нул event —
  поведение `dispatchEvent` синхронное, listener вызывается сразу.
- НЕ использовать React Context для этой задачи — слишком тяжело для
  одного boolean'а.
- НЕ использовать `useSyncExternalStore` — overkill, и нужно бы менять
  потребителей.
