# TASK-362: «100 к 1» mobile — футер под доской ответов одинаковый для обеих команд

**Тип:** simple (1 файл, 1 блок)
**Whitelist:** `src/app/game/[roomId]/hundred-to-one/page.tsx`

## Баг

Во вьюхе игрока (`s.phase === 'playing' && (myRole === 'team1' ||
myRole === 'team2')`, строка ~1187-1189):
```tsx
<div className="mt-4 text-center text-[13px] font-medium text-white/45">
  {l('Отвечает ваша команда — говорите вслух, ведущий откроет ответ', 'Your team answers aloud, the host reveals the answer')}
</div>
```
Текст статичный и не зависит от того, какая команда сейчас реально атакует
раунд (`s.roundActiveTeam[s.curQ]`, 1 или 2) — из-за этого игрок команды,
которая СЕЙЧАС НЕ отвечает, тоже видит «Отвечает ваша команда», что неверно.

## Фикс

Определи текущую команду игрока (в файле уже есть переменная `myTeam:
'team1' | 'team2' | null`, вычисленная из `myRole` — используй её или
аналогичное сравнение с `s.roundActiveTeam[s.curQ]`, где `1` = team1,
`2` = team2).

- **Раунды 1-3** (`s.curQ <= 2`): если `myTeam` совпадает с активной
  атакующей командой — показывать текущий текст («Отвечает ваша команда —
  говорите вслух, ведущий откроет ответ»). Если НЕ совпадает — показывать
  другой текст, например «Отвечает команда {имя активной команды} — ждите
  своего хода» (используй `s.t1n`/`s.t2n` по значению `s.roundActiveTeam[s.curQ]`).
- **Раунд 4** (`s.curQ === 3`, «Игра наоборот») — тут обе команды отвечают на
  один и тот же вопрос одновременно (см. экран `r4rules` выше по файлу), фраза
  «Отвечает ваша команда» тут не имеет смысла вообще ни для кого. Замени этот
  футер для `curQ === 3` на нейтральный текст про обсуждение, например
  «Обсуждайте ответ с командой — очки получит только самый редкий вариант»
  (подбери формулировку в духе уже существующих текстов раунда 4 выше по
  файлу, через `l(ru, en)`).

## Acceptance

- `npm run lint` и `npx tsc --noEmit` — чисто.
- В раундах 1-3: активная команда видит «Отвечает ваша команда...», другая —
  другой (ожидающий) текст с именем активной команды.
- В раунде 4: обе команды видят один и тот же нейтральный текст про
  обсуждение (не «Отвечает ваша команда»).
- НЕ коммитить. Отчёт в
  `codex-reports/362-h2o-mobile-active-team-footer-text.md`.
