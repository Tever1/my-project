# TASK-011.1: Press-effect на тайле через variant (фикс TASK-011)

> **Сложность:** simple
> **Запуск:** auto by Claude
> **Зависит от:** TASK-011

## Проблема

`whileTap={{ scale: 0.97 }}` на `motion.button` (parent) умножается на
существующий `scale` во внутреннем `motion.div` (variants `hover: 1.04`,
`active: 1.02`) → итого ~1.0 → визуально не видно press-effect.

## Цель

Сделать заметный press-effect через variants:
- В внутренний `motion.div` добавить `tap: { scale: 0.95, y: -1 }`.
- На корневом `motion.button` заменить `whileTap={{ scale: 0.97 }}` →
  `whileTap="tap"` (string-variant). Framer-motion прокинет его вниз
  и активирует `tap`-вариант в дочернем motion.div.

## Файлы

- `src/app/lobby-preview/page.tsx` — только.

## Шаги

В `function Tile`:

1. Найти `motion.button`, заменить:
   ```ts
   whileTap={{ scale: 0.97 }}
   ```
   на:
   ```ts
   whileTap="tap"
   ```

2. Найти внутренний `motion.div` (тот что с variants `rest/hover/active`,
   `aspectRatio: "1"`, `borderRadius: radius.md`). В variants добавить:
   ```ts
   variants={{
     rest: { y: 0, scale: 1 },
     hover: { y: -5, scale: 1.04 },
     active: { y: -3, scale: 1.02 },
     tap: { y: -1, scale: 0.95 },
   }}
   ```

3. Halo-`motion.div` (тот что с `inset: -12`, radial-gradient) — оставить
   как есть. У него свои variants (`rest: opacity 0`, `hover: 1`, `active: 0.6`)
   без scale. Можно опционально добавить `tap: { opacity: 0.4 }` для
   мягкости — но не обязательно.
