# TASK-351: «100 к 1» — БАНК на мобильном экране игроков переместить наверх (как у ведущего)

## Whitelist файлов
- `src/app/game/[roomId]/hundred-to-one/page.tsx`

## Проблема (не баг данных, а расположение блока)

На мобильном экране игроков (роли `team1`/`team2`, блок «PLAYING: PLAYER
VIEW», строки ~963-1041) БАНК раунда отображается В НИЗУ — после списка
из 6 ответов (текущий порядок: счёт команд → тип раунда → страйки →
вопрос → ответы → **БАНК**).

На экране ведущего (роль `host`, блок «PLAYING: HOST VIEW», строки
~1109-1198) порядок другой — БАНК стоит СРАЗУ после типа раунда, ДО
страйков (счёт команд → тип раунда → **БАНК** → страйки → вопрос →
ответы).

Нужно привести порядок на экране игроков к тому же порядку, что у
ведущего: БАНК должен идти сразу после блока «тип раунда», ДО блока
страйков.

## Фикс

В блоке «PLAYING: PLAYER VIEW (team1/team2)» (~строка 963-1041):

1. Вырезать текущий блок Fund (комментарий `{/* Fund */}`, строки
   ~1024-1030):
   ```tsx
   {/* Fund */}
   {s.curQ <= 2 && (
     <div className="flex items-center justify-center gap-3">
       <span className="text-xs text-white/40 font-bold">{l('БАНК:', 'BANK:')}</span>
       <span className="font-bold text-yellow-300 text-xl">{s.roundFund[s.curQ]}</span>
     </div>
   )}
   ```
2. Вставить его сразу после блока «тип раунда» (после закрывающего
   `</div>` блока с `{roundNames[s.curQ]}`, ~строка 985) и ПЕРЕД
   комментарием `{/* Strikes for BOTH teams (no team names on phones) */}`
   (~строка 986-987).
3. Стили блока при переносе не менять (тот же `className`), только
   позицию в дереве JSX. По желанию можно добавить `mb-2` для отступа
   снизу перед страйками (посмотри, как выглядит аналогичный отступ у
   ведущего между БАНК и страйками — `mb-2` уже есть на блоке БАНК у
   ведущего, строка ~1138-1146, ориентируйся на него для консистентного
   вида).

## Что НЕ трогать

- Логику начисления/сброса `roundFund` — не менять, только JSX-порядок.
- Экран ведущего (`isGameHost`) — уже в правильном порядке, не трогать.
- Экран TV (`myRole === 'tv'` внутри этого же файла, и отдельный файл
  `src/app/tv/[roomId]/[gameType]/page.tsx`) — не трогать, вопрос был
  только про мобильные экраны игроков.
- Раунд 4 (`s.curQ === 3`) — там БАНКа нет и не должно быть (условие
  `s.curQ <= 2` уже это гарантирует), не менять.

## Acceptance

- На мобильном экране team1/team2 в раунде 1-3 БАНК виден сразу под
  надписью типа раунда (ПРОСТАЯ/ДВОЙНАЯ/ТРОЙНАЯ ИГРА), над страйками —
  такой же порядок, как на экране ведущего.
- Список ответов и раунд-4-таймер остаются на прежних местах, ничего
  больше не переставлено.
- `npx tsc --noEmit` и `npm run lint` проходят.
