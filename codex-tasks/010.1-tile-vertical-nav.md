# TASK-010.1: Вертикальная навигация ↑/↓ между tile-strip и hero CTA

> **Сложность:** simple
> **Запуск:** auto by Claude
> **Зависит от:** TASK-010

---

## Цель

Расширить keyboard nav: стрелки **↑** и **↓** переключают фокус между
двумя «зонами»:
- **Зона A — hero CTA** (кнопки «Начать партию» и «Правила» в hero-секции)
- **Зона B — tile-strip** (7 тайлов внизу)

Логика:
- Когда фокус в tile-strip и пользователь жмёт **↑** — фокус переходит на
  «Начать партию».
- Когда фокус на «Начать партию» / «Правила» и жмёт **↓** — фокус возвращается
  на текущий активный тайл в tile-strip.
- Внутри hero CTA — стрелки **←/→** переключают между «Начать партию» и
  «Правила» (опционально, можно оставить только Tab).

## Шаги реализации

1. Поставить `ref` (`useRef<HTMLButtonElement>(null)`) на кнопки «Начать партию»
   (главная CTA) и активный тайл в tile-strip.

   Для активного тайла в TileStrip — проще через
   `data-game-id={game.id}` атрибут на `motion.button`, тогда искать через
   `document.querySelector(\`[data-game-id="${activeGame}"]\`)`.

2. В существующем `keydown` listener (из TASK-010) добавить:
   ```ts
   } else if (e.key === 'ArrowUp') {
     // Если фокус в tile-strip — перенести на «Начать партию»
     const focused = document.activeElement as HTMLElement | null;
     const inTileStrip = focused?.dataset?.gameId !== undefined;
     if (inTileStrip) {
       e.preventDefault();
       startGameButtonRef.current?.focus();
     }
   } else if (e.key === 'ArrowDown') {
     // Если фокус на CTA — вернуть на активный тайл
     const focused = document.activeElement as HTMLElement | null;
     const isCta = focused?.dataset?.lobbyCta !== undefined;
     if (isCta) {
       e.preventDefault();
       const tile = document.querySelector<HTMLElement>(
         `[data-game-id="${activeGame}"]`
       );
       tile?.focus();
     }
   }
   ```

3. На «Начать партию» button добавить `ref={startGameButtonRef}` и
   `data-lobby-cta="start"`.

4. На «Правила» button добавить `data-lobby-cta="rules"`.

5. На каждом `<Tile>` — `data-game-id={game.id}` (Tile принимает game в props,
   используем `game.id`).

6. Опционально (если просто): когда фокус на CTA, **←/→ переключает** между
   «Начать партию» (`data-lobby-cta="start"`) и «Правила» (`data-lobby-cta="rules"`).
   В существующем handler добавить early-return для CTA фокуса:
   ```ts
   if (e.key === 'ArrowRight' || e.key === 'ArrowLeft') {
     const focused = document.activeElement as HTMLElement | null;
     if (focused?.dataset?.lobbyCta) {
       e.preventDefault();
       const next = focused.dataset.lobbyCta === 'start' ? 'rules' : 'start';
       document.querySelector<HTMLElement>(`[data-lobby-cta="${next}"]`)?.focus();
       return;
     }
     // … existing logic для tile-strip
   }
   ```

7. Wrap-around внутри tile-strip (←/→) — оставить как есть из TASK-010,
   но добавить guard «если фокус в hero CTA — не свитчить активную игру».
