> - **Дата создания:** 2026-05-24

> - **Зависит от тасков:** —

## Цель

Убрать из лобби две кнопки которые больше не нужны в новом flow:
1. Кнопка «ТВ-режим» / «Открыть ТВ» — открывает `/tv/${roomCode}` в новой вкладке.
2. Кнопка «Создать комнату» — теперь комната создаётся автоматически при нажатии
   «Начать партию» (TASK-138). Отдельной кнопки создания не нужно.

Кнопка «Начать партию» — **остаётся**.

## Шаги реализации

### 1. Найти и удалить кнопку «ТВ-режим» / «Открыть ТВ»

Ищи в файле строку с `window.open` + `/tv/` или текст «ТВ» / «TV» / «Открыть ТВ»
в JSX. Это кнопка в TopBar, которая открывает TV-страницу в новой вкладке.
Удалить полностью весь JSX-элемент (кнопку). Логику `window.open` тоже удалить.

Пример что искать (строка ~800):
```ts
window.open(`/tv/${roomCode}`, "_blank", "noopener,noreferrer");
```

### 2. Найти и удалить кнопку «Создать комнату»

Ищи в JSX элементы с текстом «Создать комнату» / «Создать» / `createRoom` /
`isCreatingRoom` — это кнопка в TopBar или в hero-секции, которая вызывает
`createRoom()` напрямую (не через `handleStartGame`).

**Важно:** `handleStartGame` и сама функция `createRoom` — **не удалять**,
они нужны в TASK-138 для автоматического создания комнаты при старте игры.
Удалить только JSX-кнопку которая вызывает `createRoom()` напрямую.

### 3. Убрать связанные состояния (только если больше нигде не используются)

Если после удаления кнопок какие-то `useState` / `useCallback` окажутся
неиспользуемыми — удалить. Проверить через lint (`npm run lint`).
