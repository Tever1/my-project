# TASK-256 — Крокодил: высота карточки угадывающего = высоте карточки объясняющего

## Проблема
В фазе `explaining` у объясняющего под красной карточкой слова есть кнопки
«Пропустить/Угадали» (ряд высотой `h-[76px]`), поэтому карточка занимает
«экран минус кнопки». У не-объясняющего (карточка «Угадывайте вслух!») кнопок нет,
и `flex-1` растягивает её на весь экран. Нужно, чтобы карточка угадывающего была
ТАКОЙ ЖЕ высоты, как у объясняющего (как на правом скрине), а не во весь экран.

## Whitelist (ТОЛЬКО это)
- `src/app/game/[roomId]/crocodile/page.tsx`

ЗАПРЕЩЕНО: всё остальное. Минимальный diff.

## Решение
В контейнере фазы ready/explaining (`<div className="flex-1 flex flex-col items-center gap-4 w-full">`)
дети идут как flex-колонка с `gap-4`. У объясняющего внизу — блок кнопок
(`{gameState.phase === 'explaining' && isExplainer && (...)}`, ряд `h-[76px]`).
У не-объясняющего этого блока нет.

Добавить НЕВИДИМЫЙ распорка-плейсхолдер той же высоты ТОЛЬКО для
`explaining && !isExplainer`, сразу ПОСЛЕ карточки «Угадывайте вслух» (на месте,
где у объясняющего кнопки), чтобы `flex-1` карточки угадывающего совпал по высоте
с карточкой объясняющего:

```jsx
{gameState.phase === 'explaining' && !isExplainer && (
  <div aria-hidden className="w-full max-w-md h-[76px] opacity-0 pointer-events-none select-none" />
)}
```

- Высота `h-[76px]` = высоте ряда кнопок (кнопки `h-[76px]`). `gap-4` родителя
  применится одинаково (карточка → кнопки у объясняющего ≡ карточка → распорка у
  угадывающего), поэтому низ карточек выровняется.
- Карточку угадывающего НЕ менять (остаётся `min-h-[320px] flex-1 rounded-[36px]`).
- Фазу `ready` НЕ трогать (там у обоих нет кнопок, карточки уже одинаковы).
