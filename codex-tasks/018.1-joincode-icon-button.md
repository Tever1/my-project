# TASK-018.1: Join-submit как icon-only button + arrow-nav из input

> **Сложность:** simple
> **Запуск:** auto by Claude

## Цели

1. **Иконка вместо надписи**: текст «Присоединиться» убрать, на её месте
   inline SVG значок «вход» (стрелка → входящая в прямоугольник). Это
   уменьшает ширину кнопки до ~50-60px, она помещается рядом с input.
2. **Layout**: кнопка визуально справа от input на той же строке.
3. **Arrow nav из editing input**: при курсоре в конце value и
   joinCode.length===6 — ArrowRight в input → focus на join-submit.

## Файлы

- `src/app/lobby-preview/page.tsx` — только.

## Шаги

### A. Заменить текст на SVG-иконку

В существующей `motion.button` с `data-lobby-cta="join-submit"`:

1. Удалить текст «Присоединиться».
2. Вставить inline SVG (стрелка → входящая в дверной проём):
   ```tsx
   <svg
     width="22" height="22" viewBox="0 0 24 24"
     fill="none" stroke="currentColor"
     strokeWidth="2.5" strokeLinecap="round" strokeLinejoin="round"
     aria-label="Присоединиться"
   >
     <path d="M15 3h4a2 2 0 0 1 2 2v14a2 2 0 0 1-2 2h-4" />
     <polyline points="10 17 15 12 10 7" />
     <line x1="15" y1="12" x2="3" y2="12" />
   </svg>
   ```
   (door rect on right + arrow shaft + chevron).
3. Изменить размеры кнопки на icon-only:
   - `padding`: убрать большой horizontal, использовать `0` или `0 14px`.
   - `width: 60` (фикс), `height: 60` (как было).
   - `aria-label="Присоединиться к комнате"` для accessibility.

### B. Layout — без wrap для группы

Если в строке ещё проблема с wrap, обернуть join-wrapper + join-submit
в общий `<div style={{ display: 'inline-flex', gap: 12, flexShrink: 0 }}>`,
чтобы они не разрывались. Если без обёртки уже помещаются (icon-only
60px достаточно компактно) — обёртку не добавлять, оставить как есть.

### C. Arrow-nav из input

В input (внутри join-code wrapper), добавить в существующий `onKeyDown`:

```tsx
if (e.key === "ArrowRight") {
  const target = e.currentTarget;
  const isAtEnd = target.selectionStart === target.value.length
    && target.selectionEnd === target.value.length;
  if (isAtEnd && target.value.length === 6) {
    e.preventDefault();
    document.querySelector<HTMLElement>('[data-lobby-cta="join-submit"]')?.focus();
  }
}
```

Существующий Esc handler не трогать.
