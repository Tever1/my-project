# TASK-381: Реализовать роли Дон/Маньяк/Любовница в геймплее Мафии

> **Метаданные**
> - **Дата создания:** 2026-07-27
> - **Сложность:** complex
> - **Запуск:** manual by user (Codex Desktop)
> - **Ожидаемое время Codex:** ~40-60 минут
> - **Зависит от тасков:** —

---

## Цель

Расширить реальную игровую механику Мафии тремя новыми ролями — Дон, Маньяк,
Любовница — с полным ночным циклом действий, условиями победы и UI для
каждой роли. Сейчас в коде реализованы только 4 роли (mafia/detective/
doctor/citizen); эта задача добавляет три новые поверх них, не ломая
существующий 4-ролевой геймплей при малом числе игроков.

---

## Контекст

Полная спецификация ролей и порядок ночи согласованы с пользователем и
зафиксированы в `CLAUDE.md`, раздел "Спецификация: расширение ролей Мафии"
(сразу после заголовка `## Над чем работаем сейчас`). **Прочитать этот
раздел целиком перед началом** — там точные формулировки механики каждой
роли, ночной порядок разрешения и пороги ввода по количеству игроков.
Справочная таблица ролей в `/admin` уже отражает эти роли и пороги
(TASK-379/380) — это не геймплей, отдельная страница, не трогать.

Архитектура игры — **host-authoritative на клиенте**: вся логика Мафии
живёт в `src/app/game/[roomId]/mafia/page.tsx` (не в `server.mts` — сервер
только ретранслирует broadcast-события через `useGameBroadcast`). TV-режим
(`src/app/tv/[roomId]/[gameType]/page.tsx`) только отображает состояние,
не содержит логики.

**Текущая реализация для справки** (`src/app/game/[roomId]/mafia/page.tsx`):
- `assignRoles(playerIds)` (~строка 76) — раздаёт роли по количеству игроков.
- `checkWin(alive, roles)` (~строка 101) — проверяет условие победы.
- `handleResolveNight()` (~строка 414) — резолвит ночь: считает голоса
  мафии, проверяет доктора, шлёт detective-result и night-result.
- Night actions приходят как broadcast-события: `mafia-vote`,
  `detective-check`, `doctor-save` (см. `GameAction` union, ~строка 45).
- `MafiaRole`, `MafiaPhase`, `MafiaState.data` — в `src/types/game.ts`
  (~строки 128-143).

## Файлы к изменению (whitelist)

- `src/types/game.ts` — расширить `MafiaRole` до
  `'citizen' | 'mafia' | 'don' | 'maniac' | 'detective' | 'doctor' | 'lover'`,
  добавить в `MafiaState.data` поля для новых ночных действий (маньяка,
  Дона-проверки-шерифа, Любовницы) и для истории (последняя цель Любовницы,
  последняя цель доктора — для правила "не тот же игрок 2 ночи подряд").
  Расширить `winner` union, если Маньяк может побеждать соло (см. спецификацию
  в CLAUDE.md — уточнить условие его победы, если не описано явно, задать
  вопрос в отчёте, не додумывать самостоятельно).
- `src/app/game/[roomId]/mafia/page.tsx` — основная логика:
  - `assignRoles()` — добавить Дона/Маньяка/Любовницу по порогам из
    CLAUDE.md (Дон и Маньяк с 10 игроков, Любовница с 12).
  - Новые типы `GameAction` для ночных действий: `maniac-kill`,
    `don-check-sheriff`, `lover-visit` (аналогично существующим
    `mafia-vote`/`detective-check`/`doctor-save`).
  - UI ночной фазы: каждая новая роль должна видеть свой экран выбора цели
    (по аналогии с существующими экранами доктора/детектива/мафии).
  - `handleResolveNight()` — реализовать точный порядок разрешения ночи из
    CLAUDE.md: 1) мафия+Дон выбирают жертву (решающий голос Дона при
    разногласиях), 2) Любовница блокирует цель, 3) Маньяк убивает (если не
    заблокирован), 4) Доктор лечит (если не заблокирован, не лечит себя, не
    того же игрока 2 ночи подряд), 5) Шериф проверяет (если не
    заблокирован), 6) Дон отдельно проверяет на Шерифа (не блокируется
    Любовницей — это отдельный этап после общего резолва, согласно
    CLAUDE.md).
  - Блокировка Любовницы: если её цель — доктор/шериф/маньяк/Дон
    (на этапе проверки шерифа) — их действие этой ночью не засчитывается.
    Мафию/её выстрел Любовница НЕ блокирует (см. CLAUDE.md).
  - Смерть Любовницы: если её убивают этой ночью — игрок, к которому она
    ходила, тоже погибает.
  - Алиби: если днём проголосовали за игрока, к которому Любовница ходила
    этой ночью — он не выбывает несмотря на голоса (`handleResolveVotes`,
    ~строка 473).
  - `checkWin()` — учесть Маньяка как отдельную сторону (условие победы см.
    вопрос выше).
- `src/app/tv/[roomId]/[gameType]/page.tsx` — winner-баннер
  (~строка 2619-2622, сейчас только `ms.winner === 'mafia'` vs мирные) —
  добавить вариант для победы Маньяка, если он выигрывает соло.
