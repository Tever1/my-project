# TASK-324: «Кто я?» — фикс верстки бейджей «Вопросов задано» / «Да подряд»

## Контекст

TASK-323 добавила бейдж «Да подряд: N/3» рядом с существующим «Вопросов
задано: N» в мобильном экране `who-am-i`. Живое QA (реальный телефон)
показало 2 проблемы:

1. На узком экране бейдж «Да подряд» наезжает на «Вопросов задано» —
   они не помещаются в один ряд (`glass-badge` + `glass-badge ml-2`).
2. Формулировка «Да подряд: N/3» — слово «Да» нужно взять в скобки:
   «(Да) подряд: N/3» (по требованию продакта, без объяснений — просто
   визуальное уточнение, что «Да» это литеральный ответ, а не часть
   фразы).

## Файл

`src/app/game/[roomId]/who-am-i/page.tsx`, около строк 500-509:

```tsx
<div className="text-center mb-3">
  <span className="glass-badge">
    {l(`Вопросов задано: ${myQuestions}`, `Questions asked: ${myQuestions}`)}
  </span>
  <span className="glass-badge ml-2">
    {l(
      `Да подряд: ${gs.consecutiveYesAnswers}/3`,
      `Yes streak: ${gs.consecutiveYesAnswers}/3`,
    )}
  </span>
```

## Что сделать

1. **Layout:** переверстать так, чтобы бейджи не наезжали друг на друга
   ни на узких экранах. Проще всего — обернуть оба `<span>` в
   `flex flex-col items-center gap-2` (вертикально, один под другим)
   вместо текущего inline+`ml-2`. Не меняй стиль самих `glass-badge`
   (класс не трогать), только контейнер/расположение.
2. **Текст:** заменить `Да подряд:` на `(Да) подряд:` (RU), английскую
   версию `Yes streak:` оставить как есть (скобки — только по русской
   формулировке, продакт просил именно так).
