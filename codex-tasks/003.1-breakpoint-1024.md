# TASK-003.1: Поднять breakpoint 900 → 1024

> **Метаданные**
> - **Дата создания:** 2026-05-03
> - **Сложность:** simple
> - **Запуск:** auto by Claude
> - **Ожидаемое время Codex:** ~1 минута

## Цель

QA после TASK-003 показал что даже с `whiteSpace: nowrap` TopBar overflowает
viewport на 901-1023px (полная сумма ширин desktop-элементов = 943px при
viewport 901px). На 1024+ всё помещается чисто.

Поднять breakpoint в `useIsMobile` с 900 до 1024, чтобы 901-1023 показывал
mobile layout (заведомо помещается), а 1024+ — full desktop.

---

## Файлы к изменению (whitelist)

- `src/app/lobby-preview/page.tsx`

---

## Шаги

В функции `useIsMobile`:

```tsx
function useIsMobile(breakpoint = 900) {
```

Заменить на:

```tsx
function useIsMobile(breakpoint = 1024) {
```

Это всё.
