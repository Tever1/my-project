# TASK-013.1: Snappy transition для whileTap на тайле

> **Сложность:** trivial, ~30 секунд
> **Запуск:** auto by Claude

## Проблема

Press-effect едва виден — при click scale достигает только 0.98 вместо 0.92,
потому что `transition={spring.soft}` (stiffness 200) слишком медленный.
За ~80ms клика анимация не успевает дойти до целевого scale.

## Цель

Сделать tap-анимацию snappy — она должна успевать за время реального клика.
Hover/active останутся на soft.

## Файлы

- `src/app/lobby-preview/page.tsx` — только в `function Tile`.

## Шаг

В `motion.button` внутри Tile, изменить:
```tsx
whileTap={{ scale: 0.92 }}
```
на:
```tsx
whileTap={{ scale: 0.92, transition: { type: "spring", stiffness: 600, damping: 25 } }}
```

(или `transition: spring.stiff` если такая константа есть в `@/lib/design/tokens`).

ВСЁ. Один атрибут. Не трогай ничего больше.
