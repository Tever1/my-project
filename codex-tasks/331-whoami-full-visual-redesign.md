# TASK-331: «Кто я?» — полный визуальный редизайн (mobile + TV) по утверждённому макету

## Контекст

Игра «Кто я?» (`who-am-i`) сейчас работает функционально (вся логика на
месте, включая TASK-323…330: механика передачи хода «Да»/«Нет», механика
«оспорить ответ» по образцу Spy, черновой TV-рендер), но визуально не
доведена — использует старый фиолетовый акцент вместо утверждённого
голубого цвета игры, эмодзи вместо иконок, нет фирменных анимаций
(«дышащий» фон, spring-тосты, reveal по очереди в финале и т.д.), которые
уже есть у остальных 6 игр (Crocodile/Spy/Alias/Mafia/Quiz/100-к-1).

Это ЧИСТО визуальный редизайн. **Игровую логику, socket-события,
структуру состояния — НЕ ТРОГАТЬ.** Только внешний вид существующих
экранов/фаз.

## Что делать

### Whitelist файлов (СТРОГО, ничего за пределами)

- `src/app/game/[roomId]/who-am-i/page.tsx` (мобильный экран)
- `src/app/tv/[roomId]/[gameType]/page.tsx` (TV, только блок
  `gameType === 'who-am-i'` и связанный код — НЕ трогай блоки других игр)
- `src/components/games/WhoAmIIcon.tsx` (новый файл)

### Мобильный экран (`who-am-i/page.tsx`)

Редизайн по разделу 2.1 брифа + макетам `Phone - *.html`:
- Заменить весь фиолетовый акцент (`purple-500`, `purple-300` и т.п.) на
  голубой игры (`#38bdf8` / `#0284c7`, либо через существующий токен игры
  в `src/lib/design/tokens.ts` если он там уже определён для `who-am-i`).
- Заменить все эмодзи (⭐👉✅🎉❌🏆🥇🥈🥉🤔) на иконки из нового
  `WhoAmIIcon.tsx` (таблица соответствия — раздел 5 брифа; ✅ на
  мобильном НЕ используется вообще — статус угаданных показывается
  только на TV, см. TASK-330, уже сделано, не восстанавливай).
- Индикатор серии «Да подряд: N/3» — сделать визуально аккуратным
  (точки/прогресс-бар/что уместно), логику счётчика НЕ трогать.
- Экраны оспаривания и судьи (уже есть по TASK-329) — довести визуал по
  макетам `Оспаривание.html`/`Судья.html`: янтарный тон для оспаривания,
  зелёный/красный для вердикта судьи (семантические цвета, НЕ голубой
  акцент игры — см. раздел 4 брифа, эти цвета про результат действия,
  не про идентичность игры).
- Финальная таблица — цветовой код ранга через фон/рамку карточки
  (золото/серебро/бронза, приглушённые тона) + иконка `WaMedal` вместо
  эмодзи, по образцу того, как уже сделано в Alias/Crocodile (смотри их
  файлы как референс паттерна, НЕ копируй один в один — у «Кто я?» свой
  голубой акцент).
- Кнопки — использовать существующие варианты `GlassButton`
  (`primary`/`default`/`danger`) по таблице раздела 3 брифа, не
  изобретать новые стили кнопок.

### TV экран (`tv/[roomId]/[gameType]/page.tsx`, блок who-am-i)

Довести черновик до финального вида по разделу 2.2 брифа + макетам
`TV - *.html`:
- **lobby**: крупная иконка `WaProfile`, заголовок, подзаголовок, QR/код
  (существующий паттерн `qrOverlay`, не трогать), список подключённых
  игроков.
- **playing**: HUD-шапка (иконка+название слева, «Сейчас ходит: {имя}» по
  центру, «Угадали: X из Y» справа). Центр — hero-карточка активного
  игрока с **маскировкой персонажа** (см. брифинг: скрыт, пока не угадал
  ИЛИ пока не передал ход), пульсирующее кольцо вокруг карточки (не
  статичная обводка). Под hero — компактный горизонтальный мини-ряд
  остальных игроков (никнейм + иконка `WaCheck`/аналог приглушённо-зелёным
  если угадал), без персонажей в мини-ряду. **Обязательно проверь на 10+
  игроках** (макет `· 10 игроков.html`) — ряд должен сжиматься по
  паддингам/шрифту, не скроллиться и не вылезать за экран.
- Полноэкранный overlay попытки угадать (`AnimatePresence`, cross-fade):
  правильно → иконка `WaCelebrate`, акцентный голубой, spring-«отскок»
  анимация появления (`cubic-bezier(.2,.9,.3,1.3)`, по образцу
  макета `TV - Угадала!.html`); неправильно → иконка `WaCross`,
  приглушённый красный.
- Во время флоу оспаривания — нейтральный нейтральный нейтральный
  баннер «Игрок оспаривает ответ...» (уже есть по TASK-329), довести
  визуал по макету `TV - Оспаривание.html` — БЕЗ деталей вердикта на TV
  (TV не должен быть подсказкой судье).
- **finished**: reveal «по очереди, шоу-формат» — заголовок «Игра
  окончена!» первым, затем карточки раскрываются одна за другой СНИЗУ
  ВВЕРХ по таблице (сначала последнее место, последним — победитель),
  интервал ~0.4-0.6с (ближе к 0.3-0.4с при 10+ игроках, см. брифинг
  «важно для 10+ игроков»), топ-3 подсвечены иконкой `WaMedal` с
  цветовым кодом ранга. Проверь на макете `· 10 игроков.html`.
- Фон — «дышащий» radial-glow голубого поверх тёмного per-game
  градиента (раздел 4 брифа — готовые CSS-градиенты можно взять как
  основу), вместо статичного/нейтрального текущего фона. Через
  `GameSurface`, не пиши фон руками (см. правило проекта №7 — если
  видишь `<img class="-z-10">` руками где-то в другом месте файла, это
  чужой код других игр, не трогай; для блока who-am-i используй тот же
  паттерн `GameSurface`, что и у остальных игр в этом файле).

### Что НЕ делать

- НЕ менять игровую логику, socket-события (`who-am-i:*`), структуру
  `WhoAmIGameState`.
- НЕ менять список персонажей (`WHO_AM_I_CHARACTERS`).
- НЕ добавлять новые фичи сверх дизайна (таймер на ход, звук и т.п.) —
  бриф явно говорит: таймер на ход РЕШЕНО не делать.
- НЕ трогать блоки других игр в TV-файле.
- НЕ ломать i18n — если в текущем коде игры уже есть строки на ru/en
  (`useTranslation`/`l(ru,en)` паттерн), сохранить двуязычность для
  любого нового/изменённого текста.
