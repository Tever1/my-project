## Цель

Две точечные правки по результатам QA TASK-002:

1. На viewport 769–900px desktop layout слишком плотный (имя "Аня" обрезается,
   "Создать комнату" в 2 строки). Поднять breakpoint mobile/desktop с 768 до 900.
2. На viewport 375px бренд "Party Hub" в TopBar переносится на 2 строки.
   Добавить `whiteSpace: 'nowrap'` на текстовом элементе бренда.

Десктоп ≥ 901px и поведение mobile ≤ 768px не должны измениться.

---

## Контекст

QA TASK-002 показал что breakpoint 768 даёт desktop-layout начиная с 769px,
но в этом диапазоне (769-900) элементы TopBar плотно прижаты и тексты
обрезаются. Поднятие до 900 решает: 769-900 будет mobile (стэкнутый, читаемый),
901+ — полноценный desktop с местом.

Параллельно на 375px текст "Party Hub" в `<BrandMark>` переносится — flex
squeeze. Решение: nowrap на тексте.

## Шаги реализации

### 1. Breakpoint 768 → 900

В функции `useIsMobile` (около строки 106):

```tsx
function useIsMobile(breakpoint = 768) {
```

Заменить на:

```tsx
function useIsMobile(breakpoint = 900) {
```

Это всё. Все вызовы `useIsMobile()` без аргумента автоматически подхватят новое
значение по умолчанию.

### 2. BrandMark nowrap

В функции `BrandMark` (около строки 258), внутри второго `<div>` где написано
"Party Hub", добавить `whiteSpace: 'nowrap'` в style-объект:

```tsx
<div
  style={{
    fontWeight: 700,
    fontSize: 17,
    letterSpacing: "-0.02em",
    whiteSpace: "nowrap",   // ← добавить эту строку
  }}
>
  Party Hub
</div>
```
