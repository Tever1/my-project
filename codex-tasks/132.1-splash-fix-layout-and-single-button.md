## Контекст

В TASK-132 Splash использовал `<GlassButton variant="secondary">`, у которого
`.glass-button-secondary` имеет `display: inline-flex` + `white-space: nowrap`.
Это распирает кнопку по горизонтали и выталкивает многострочный контент
(`<span class="block">…</span>` внутри) за её визуальные границы, при этом
кликабельная область остаётся на самой кнопке. Пользователь видит надпись
снаружи, кликает по тексту — `onClick` не срабатывает.

Параллельно меняем UX: вместо двух кнопок — одна, автоматически выбранная
через `useIsMobile()`. Если пользователь зашёл не с того устройства — он может
сбросить выбор через `?reset-mode=1` (это уже работает) или (в будущем)
переключить из настроек профиля.

## Шаги реализации

1. **Убрать `GlassButton` из Splash.** Использовать вместо него обычный
   `<motion.button>` с inline-стилями (или Tailwind `flex flex-col`) —
   полный контроль над layout. Высота min-h-[180px], width 100%, max-width
   ~440px. Внутри — flex column, items-center, gap.

2. **Логика кнопки — авто-детект, одна кнопка:**
   ```tsx
   const isMobile = useIsMobile();
   const targetMode: PlayMode = isMobile ? "mobile" : "desktop";

   const label = isMobile ? "Играть на телефоне" : "Играть";
   const subtitle = isMobile
     ? "присоединиться к комнате по QR"
     : "запустить игру на этом экране";
   ```
   Только одна кнопка. По клику → `setMode(targetMode)`.

3. **Layout кнопки** (примерный JSX):
   ```tsx
   <motion.button
     type="button"
     onClick={() => setMode(targetMode)}
     whileTap={{ scale: 0.97 }}
     transition={{ type: "spring", stiffness: 400, damping: 22 }}
     className="
       flex w-full max-w-md flex-col items-center justify-center gap-3
       rounded-3xl border border-white/15 bg-white/[0.06]
       px-8 py-10 text-center
       ring-2 ring-[var(--color-game-quiz)]
       shadow-[0_0_40px_rgba(250,204,21,0.30)]
       transition-all duration-200
       hover:bg-white/[0.10] hover:border-white/25
       focus-visible:outline-none focus-visible:ring-4
     "
   >
     <span className="text-3xl font-black leading-tight text-white sm:text-4xl">
       {label}
     </span>
     <span className="text-base font-medium text-white/70 sm:text-lg">
       {subtitle}
     </span>
   </motion.button>
   ```
   **Критично:** никакого `white-space: nowrap`. Текст должен переноситься
   на узких экранах (375px).

4. **Centering всего splash.** Сохранить fade-in motion 200ms на корневом div.
   GlassPanel оставить как обёртку (он не ломает layout). Внутри:
   - `<h1>Party Games Hub</h1>` — крупный заголовок (text-5xl/6xl)
   - `<p>Где вы играете?</p>` — подзаголовок (text-xl, white/70)
   - кнопка — единственная, центрированная

5. **Удалить весь dual-button код** (массив `options`, map, recommended-логика).
   Не должно остаться следов второй кнопки.

6. Прогнать `npm run lint` и `npx tsc --noEmit`.

## Ограничения и подводные камни

- **Никакого `nowrap` и `text-overflow`** — текст обязан переноситься.
- **Высота кнопки фиксированная** (`min-h`), чтобы две строки текста не дёргали
  layout при ресайзе window.
- **Не использовать `GlassButton`** в Splash — там CSS-конфликт. Inline-стили / Tailwind напрямую.
- **`useIsMobile()`** — SSR-safe, начальное значение `false`. Это значит что
  первый рендер на десктопе и на мобильном будет одинаковый («Играть»), а после
  hydration на мобильном переключится на «Играть на телефоне». Это нормально для
  внутренней точки входа — никто не успеет кликнуть за 50мс до hydration.
- Только русский.
