# TASK-010.3: ↑/↓ навигация между TopBar, hero CTA и tile-strip

> **Сложность:** simple
> **Запуск:** auto by Claude
> **Зависит от:** TASK-010/010.1/010.2

---

## Цель

Расширить вертикальную навигацию: добавить **TopBar** как третью «зону»
сверху. Иерархия с верха вниз: TopBar → hero CTA → tile-strip.

Поведение:
- **↑** из hero CTA («Начать партию» / «Правила») — фокус на TopBar
  (на первый интерактивный элемент в TopBar — кнопку «Играть»).
- **↓** из TopBar — фокус возвращается на hero CTA «Начать партию».
- **←/→** внутри TopBar — переключают между его кнопками
  (Играть / Друзья / История / RoomButton). Без wrap-around (по краям
  стопится). FriendsOnlinePill и AvatarPill — это `<div>`, они
  не focusable, скипаем их.

## Шаги

1. Пометить интерактивные элементы TopBar `data-topbar="<id>"`:
   - NavButton «Играть» → `data-topbar="play"`
   - NavButton «Друзья» → `data-topbar="friends"`
   - NavButton «История» → `data-topbar="history"`
   - RoomButton → `data-topbar="room"`

   Передать новый prop `topbarId?: string` в `NavButton` и `RoomButton`,
   прокинуть как `data-topbar={topbarId}` на их корневой button.

2. В `keydown` listener добавить ветки:

   ```ts
   } else if (e.key === "ArrowUp") {
     // Существующая логика — из tile-strip / body → CTA — оставить.
     // Новая логика — из CTA → TopBar (на первый topbar элемент).
     const focusedCta = focused?.dataset?.lobbyCta !== undefined;
     const inTileStrip = focused?.dataset?.gameId !== undefined;
     const isOnBody = !focused || focused.tagName === 'BODY' || focused.tagName === 'HTML';

     if (focusedCta) {
       e.preventDefault();
       document.querySelector<HTMLElement>('[data-topbar="play"]')?.focus();
       return;
     }
     if (inTileStrip || isOnBody) {
       e.preventDefault();
       startGameButtonRef.current?.focus();
       return;
     }
   } else if (e.key === "ArrowDown") {
     // Существующая логика — из CTA → активный тайл — оставить.
     // Новая логика — из TopBar → CTA.
     const inTopBar = focused?.dataset?.topbar !== undefined;
     if (inTopBar) {
       e.preventDefault();
       startGameButtonRef.current?.focus();
       return;
     }
     // … existing ArrowDown logic
   }
   ```

3. Для **←/→ внутри TopBar**: расширить ветки `ArrowLeft`/`ArrowRight`,
   добавив early-return если `focused?.dataset?.topbar`:

   ```ts
   if (e.key === "ArrowRight" || e.key === "ArrowLeft") {
     const inTopBar = focused?.dataset?.topbar !== undefined;
     if (inTopBar) {
       e.preventDefault();
       const order = ['play', 'friends', 'history', 'room'];
       const cur = focused.dataset.topbar!;
       const idx = order.indexOf(cur);
       if (idx === -1) return;
       const dir = e.key === "ArrowRight" ? 1 : -1;
       const next = idx + dir;
       if (next < 0 || next >= order.length) return; // без wrap
       document.querySelector<HTMLElement>(`[data-topbar="${order[next]}"]`)?.focus();
       return;
     }
     // ... existing CTA ←/→ logic
     // ... existing tile-strip ←/→ logic
   }
   ```

   Порядок `['play', 'friends', 'history', 'room']` соответствует
   визуальному порядку. Если в каком-то layout элемент отсутствует
   (например на mobile nav скрыта) — querySelector вернёт null,
   safely no-op.

## Ограничения

- Не трогать `FriendsOnlinePill` и `AvatarPill` (они не focusable, не
  добавляем `data-topbar`).
- Mobile (≤1024px) — nav скрыт, RoomButton остаётся. На mobile навигация
  стрелками бессмысленна (нет клавы), не отключай явно.
- Inline решение, без новых файлов.
